疑难排解

模组没反应时照这章查。九成问题是 JSON 格式或名字打错。

先做这三件事

  1. 回标题画面，再“开始新游戏”或“读取存档” —— 数据在这两个时机才合并，这是最常见的原因
  2. 确认模组是启用状态 —— 标题画面 → 模组，开关要是打开的
  3. 把 JSON 贴到线上检查工具验一次 —— 搜索“JSON validator”，任何一个都行
大部分问题到这里就解决了 还是不行的话往下看按症状分类的检查。

症状：模组列表里没有我的模组

检查说明
有 mod.json 吗最常见原因。没有这个档，文件夹会被完全忽略
文件名对吗必须正好是 mod.json，不是 Mod.json 或 mod.json.txt
放对地方了吗Mods/你的模组/mod.json，不是 Mods/mod.json
层数对吗只扫 Mods/ 的直接子文件夹。放到孙层不会被找到
有“模组”按钮吗手机版和 Demo / 试玩版没有模组功能
小心 Windows 隐藏扩展名 记事本存档时容易变成 mod.json.txt，而 Windows 默认不显示 .txt —— 看起来叫 mod.json，实际不是。
在文件资源管理器开启“检视 → 扩展名”确认。

症状：模组出现在列表但被标记为坏掉

代表 mod.json 存在但格式错误。

常见错误示例
最后一个字段多了逗号"author": "某人", 后面就是 }
中间字段漏了逗号两行之间没有 ,
用了单引号'name' 应该是 "name"
引号没关"name": "我的模组
用了反斜线没跳脱"icon": "art\icon.png" 应该用 /
文件不是 UTF-8中文变乱码时的原因。存档时选 UTF-8

症状：模组有启用，但数据没生效

检查说明
Name 有打错吗最常见原因。打错就变成“新增一笔”而不是“修改”。注意全形半形、空格、简繁
字段名大小写对吗SellPrice 不是 Sellprice。打错会被安静忽略
文件夹名对吗Data/Item/ 不是 Data/Items/
JSON 放对层数了吗必须是 Data/<表名>/文件.json。直接放 Data/文件.json 不会被加载
该加引号的加了吗装备能力值字段是文字，要写 "Atk": "20"
回标题重进了吗改完要回标题“开始新游戏”或“读取存档”才会套用
数据放在 Data/ 底下但没有子文件夹 = 不会加载 旧版的模组格式是直接放 Data/*.json，现在已经不支持。 必须放进表名文件夹：Data/Item/我的道具.json。
旧格式的 .csv 档也不再读取。

症状：名字或介绍是空白的

漏填 Name_I2 Name 只是内部识别码，玩家看到的是 Name_I2。
不做多语言也一定要填 Name_I2，直接写你的母语就好。

症状：图片没出现

见 加入图片 的检查列表。最常见的是：

  • 文件夹写成 Image/（漏了 s），正确是 Images/
  • 子文件夹名大小写错（Rolehead vs RoleHead）
  • 数据里的 ImageName 多写了 .png
  • 文件其实是 JPG 改成 .png 的（要真的转档）

症状：音乐没声音

见 加入音乐音效 的检查列表。最常见的是：

  • 放了音频文件但没在 Data/BGM/ 注册
  • 注册的 Name 跟音频文件文件名不一致
  • 开机后太快测试（音频文件在背景加载，等几秒再试）
  • 文件格式不支持（只吃 OGG / MP3 / WAV）
字段名打错时，游戏会告诉你正确的名字 实际的消息长这样： 
[ModPatch] Item/ExamplePotion.json 第 1 笔：
  TheItem 没有字段“IconImage”，跳过。你想找“IconName”吗？
所以不确定字段名时，故意打一个接近的， 游戏的提示会告诉你正确拼法。比翻文件快。
那是个友善又可爱的小服务。

看游戏的错误消息

游戏会把模组加载的过程写进日志。里面有明确的错误原因，比猜快得多。

日志位置：

C:\Users\<你的使用者名>\AppData\LocalLow\<公司名>\<游戏名>\Player.log
怎么找 在文件资源管理器的位址栏粘贴 %USERPROFILE%\AppData\LocalLow 按 Enter， 然后往下找游戏的文件夹。

用记事本开启，搜索 [Mod 就能看到所有模组相关消息。

消息对照表

消息片段意思怎么修
mod.json 解析失败 JSON 格式错误 用 JSON 检查工具验证 mod.json
略过“XXX”：mod.json 解析失败 整个模组被跳过 同上。修好格式后重开
没有….json（提到 Data 底下） JSON 直接放在 Data/，没放进表名文件夹 移到 Data/<表名>/ 底下
.csv 已不再… 用了旧版格式 改写成 JSON，放进表名文件夹
读取失败 文件读不到或格式坏 检查该文件的 JSON 格式与编码（要 UTF-8）
部分数据套用失败 字段名或型别有问题 消息后面会说是哪个字段，照着改
不是合法的 PNG，略过 文件不是真的 PNG 用绘图软件重新输出成 PNG，不要只改扩展名
不支持的音频文件格式，略过 音频文件格式不对 转成 OGG / MP3 / WAV
音频文件解码后是空的 音频文件坏了或是 0 字节 重新输出音频文件
已套用 N 个模组、共 M 个数据 这是成功消息 数字对不对？少了就是有文件被跳过，往上找警告
找“已套用 N 个模组”这行最快 它会告诉你实际加载了几个模组、几个数据文件。数字跟你预期的不符， 就往上翻看有什么警告。

还是解决不了

回报问题时请附上：

  • 你的 mod.json 内容
  • 出问题的那个 JSON 档内容
  • 模组的文件夹结构（截图或文字都行）
  • Player.log 里所有含 [Mod 的行
游戏内建回报功能 游戏中按 F10 可以开启问题回报，会自动附上必要的信息。

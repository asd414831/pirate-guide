加入音乐音效

模组可以带自己的 BGM 和音效。

基本规则

Mods/<你的模组>/Music/<任意子文件夹>/<音文件名>.ogg
项目说明
支持格式OGG / MP3 / WAV
推荐格式OGG —— 文件小、加载快、无授权问题
子文件夹随你怎么分，不影响查找

命名是“纯文件名”，不含路径

这点跟图片不同，最容易搞混 音乐的子文件夹纯粹给你自己整理用，游戏查找时只看文件名。
Music/BGM/MyTheme.ogg 和 Music/随便/乱/MyTheme.ogg 对游戏来说完全一样，都是“MyTheme”。

所以下面这两种放法效果相同：

Music/
├── BGM/
│   └── MyTheme.ogg          → 游戏认得的名字是 "MyTheme"
└── Sfx/
    └── se_MyHit.ogg         → 游戏认得的名字是 "se_MyHit"
Music/
├── MyTheme.ogg              → 一样是 "MyTheme"
└── se_MyHit.ogg             → 一样是 "se_MyHit"
不同文件夹撞名 = 其中一个消失 因为查找只看文件名，Music/BGM/Theme.ogg 和 Music/Sfx/Theme.ogg 会互相冲突，只有一个会生效。
建议自己加前缀避开：BGM_ / se_。

加一首 BGM

两个步骤，缺一个都没声音。

1. 放音频文件

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. 注册到 BGM 列表

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "曲子的说明文字",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "作曲者"
}
只放音频文件不注册，或只注册不放音频文件，都是安静失败
  • 只放音频文件 → 游戏里没有任何地方会用到它
  • 只注册 → 列表里看得到名字，播放时没有声音
两种情况都不会有错误消息。
ID 必须大于 0，否则不会出现在列表 ID 是 0 或负数的数据会被当成占位列跳过。
建议用 9000 以上的数字，避开游戏本体未来新增的内容。
其他字段
  • Name —— 要跟音频文件文件名一致（不含 .ogg）
  • Desc —— 曲子的说明文字
  • Path —— 纯显示用，写音频文件文件名就好
  • Maker —— 作曲者
音乐列表默认是锁著的 玩家第一次在游戏里实际播到这首时会自动解锁，不用另外设定。

换掉本体的音乐

用跟本体一样的文件名，就会盖掉。不需要注册（本体已经注册过了）：

Music/BGM_Title.ogg      <-- 换掉标题画面音乐
模组音频文件优先于本体音频文件 跟图片一样的规则。想做“全部换成自己的配乐”的模组完全可行。

音效

音效跟 BGM 走同一个文件夹，规则完全一样。差别只在音效不需要注册到列表 —— 它是由技能或演出指定名字来播放的。

Music/Sfx/se_MyHit.ogg

然后在技能或演出里指定播放 se_MyHit。

加载时机（重要）

音频文件在背景慢慢加载，开机后前几秒可能还没好 跟图片不同，音频文件（尤其 MP3）要花时间解码。游戏的做法是：
开机时先记住有哪些文件（很快），然后在背景逐个解码。
所以“游戏刚开机的前几秒”播放模组音乐，可能会没声音或播到本体的音乐。 等一下再播就正常了。
要改成同步的话，得动游戏里每一个播音乐的地方。所以就这样了。
这不是 bug，也不需要处理 实际游玩时玩家不会在开机瞬间就进到用模组音乐的场景。 但你自己测试时如果“第一次没声音、再试一次就有”，原因就是这个。

文件大小建议

用途建议理由
BGMOGG，2～5 MB循环播放的曲子，用 OGG 压缩效率最好
音效OGG 或 WAV，< 500 KB短音效用 WAV 也可以，解码最快
避免大档 WAV一首 WAV 的 BGM 可能 50 MB 以上，加载慢又占空间

检查列表

没声音的时候按顺序检查：

  1. 音频文件放在 Music/ 底下吗？
  2. 格式是 OGG / MP3 / WAV 吗？（不是改扩展名，要真的转档）
  3. 要当 BGM 的话，Data/BGM/ 有注册吗？
  4. 注册的 Name 跟音频文件文件名完全一致吗？（不含扩展名）
  5. 有跟其他音频文件撞名吗？
  6. 是不是开机后太快就测试了？（等几秒再试）
  7. 回标题重新“开始新游戏”或“读取存档”了吗？
音乐的授权是你的责任 发布模组时请确认你有权使用那些音频文件。使用他人作品前要取得授权， 或选择明确标示可自由使用的素材。

修改游戏数据

模组最主要的功能。改既有的数值，或凭空加新内容。

基本规则

Mods/<你的模组>/Data/<表名>/<任意文件名>.json
  • 文件夹名决定改哪张表 —— Data/Item/ 改道具，Data/Role/ 改角色
  • 一个 JSON 档就是一笔数据 —— 一个道具一个档，不要把多笔塞进一个档
  • 文件名不重要 —— 游戏看的是文件里的 Name 字段。文件名纯粹给你自己好认
写 Item 或 TheItem 都可以 游戏内部的表名是 TheItem，文件夹写 Item 时会自动补上 The。 两种写法都收，少一个踩雷点。

合并规则（最重要的一节）

游戏已经有一整份数据。你的 JSON 是叠在上面，不是取代它。 比对的依据是 Name 字段：

你的 Name结果
游戏里已经有同名的 就地修改。只改你写到的字段，其他字段保持原值
游戏里没有同名的 新增一笔，加在列表最后面
只写你要改的字段就好 想让某个道具卖贵一点，整个文件只要两行：
{ "Name": "药草", "SellPrice": 500 }
其他字段（名称、图标、效果）完全不受影响。
没有“删除”功能 模组不能移除游戏既有的内容。想让某个东西不出现，用 UnlockCon 设一个永远不成立的条件来隐藏它，而不是试图删除。
因为设计者…不想做。他想避免不必要的麻烦。

Name 是身份证

Name 打错 = 变成新增 想改“药草”但打成“药革”，游戏不会报错 —— 它会认为你要新增一个叫“药革”的道具。 结果：原本的药草没变，多了一个奇怪的新道具。
模组没生效时，第一个要检查的就是 Name 有没有打错（包含全形半形、空格）。

字段名怎么查

字段名要跟游戏内部一致，大小写也要对。最可靠的查法是用演出编辑器的数据表功能 （见 演出编辑器），它会列出每张表的所有字段。

字段名打错会被安静忽略 把 SellPrice 打成 Sellprice（小写 p），游戏不会报错， 那一行就是没有效果。改完没反应时要检查大小写。

型别：什么时候加引号

JSON 的数字和文字写法不同，要跟游戏的字段型别对上。

{
  "Name": "超强药水",
  "SellPrice": 500,          数字，不加引号
  "AddHP": 999,              数字，不加引号
  "Name_I2": "超强药水",     文字，要加引号
  "Atk": "20"                文字，要加引号（见下方说明）
}
装备的能力值字段是“文字”，不是数字 Atk / MaxHP / AtkPercent 这类字段存的是算式字符串， 所以要写成 "Atk": "20" 而不是 "Atk": 20。
这样设计是为了让数值能随等级变化。不确定某栏要不要加引号时， 去看游戏本体同类型的数据怎么写的，照抄那个格式。

新增内容要填 ID

新增的数据 ID 必须大于 0，否则会被跳过 ID 是 0 或负数的数据被视为占位列，不会出现在游戏里。
建议用 9000 以上的数字，避开游戏本体未来新增的内容。
修改既有数据时不用填 ID（原本的会保留）。

列表型字段

有些字段可以放多个值，JSON 写成数组：

{
  "Name": "某个角色",
  "Skill": ["斩击", "重斩", "回旋斩"]
}
数组是“整条取代”，不是“追加” 上面这样写，该角色的技能就只有这三个，原本的会被换掉。
想保留原有技能再加新的，你得把原有的也一起列出来。
为什么不做成追加：同一个模组被套用两次时，追加会变成 ["斩击","重斩","斩击","重斩"]。取代的行为才是可预期的。

逗号分隔的字段

有些字段游戏内部存成“一串用逗号隔开的文字”（例如道具的 Tag）。 这种字段两种写法都可以，效果一样：

"Tag": "战斗中可用,水果"
"Tag": ["战斗中可用", "水果"]

示例：改既有道具

Data/Item/药草改价.json

{
  "Name": "药草",
  "SellPrice": 500
}

只有卖价变了，其他一切不动。

示例：新增道具

Data/Item/SuperPotion.json

{
  "Name": "超强药水",
  "Name_I2": "超强药水",
  "Desc": "喝下去会变得很强",
  "Type": "道具",
  "IconName": "Potion",
  "SellPrice": 1000,
  "AddHP": 999,
  "AddMP": 99
}
IconName 可以借用本体的图 填游戏既有的图标名称就会用那张图。想用自己画的图见 加入图片。

示例：让敌人变强

Data/Enemy/史莱姆强化.json

{
  "Name": "史莱姆",
  "MaxHP": "200",
  "Atk": "30"
}

多语言

游戏支持繁中 / 简中 / 英文 / 日文 / 韩文 / 俄文。 名称与说明字段带 _I2 的是给翻译系统用的。

漏填 Name_I2 会让名字整个空白 Name 只是内部用的识别码，玩家看到的是 Name_I2。 只填 Name 没填 Name_I2 的话，游戏里名字和介绍都会是空的， 而且不会有任何错误消息。
不做多语言也一定要填 Name_I2，直接填你的母语文字就好。
文字结尾不要放标点符号 翻译系统会把结尾的标点当成分隔符，导致翻译查不到。
不要写 "造成大量伤害。"，要写 "造成大量伤害"。
句中的逗号也建议换成半形空格："场景过场中 无法存档"。

套用顺序

模组数据在游戏开机时套用，顺序是：

  1. 游戏加载自己的数据
  2. 模组依序叠上去（多个模组时，后面的盖前面的）

模组永远叠在最上层，所以你的修改一定生效。多个模组互相冲突的情况见 多模组共存。

改完要回标题重新进入游戏 数据在“开始新游戏”与“读取存档”时合并。改完文件后回标题再进一次就会生效， 不需要关掉游戏重开。进行中的游戏不会即时变动。

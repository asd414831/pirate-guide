演出与发放内容

写进数据表只代表“这东西存在”。玩家还没有它。这章讲怎么真的发给玩家。

这是最容易漏掉的一步 你在 Data/Role/ 加了一个角色，数据完全正确 —— 但玩家永远不会拿到他。
道具有价格字段可以自动上架，角色和关卡没有。 唯一的发放途径是演出指令。

演出是什么

演出（Show）是一串游戏指令。可以是剧情对话，也可以是纯粹的数据操作。 放在 Data/Show/，一个演出一个档。

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddRole>新角色"
  ]
}
演出只有四个字段 ID / Name / Tag / Shows。 没有说明字段，写了会被跳过。

AutoRun：模组唯一能主动做事的钩子

Tag 填 AutoRun，这个演出就会在 开新游戏 / 读取存档后自动播放。

Data/Show/AutoRun.json

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddRole>新角色",
    "<AddItem>超强药水,1"
  ]
}
AutoRun 每次都会跑，不是只跑一次 每次“开始新游戏”和“读取存档”都会执行一遍。
这通常无害 —— <AddRole> / <AddItem> 对已经持有的对象会直接跳过，不会重复给、也不会把等级打回 1。

真的只想跑一次，自己用标志包起来：

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<if>{我的模组已初始化}==0",
    "<AddRole>新角色",
    "<Var>我的模组已初始化,=,1",
    "<endif>"
  ]
}
Name 直接用你的模组名称 Name 是合并用的 key，两个模组的 AutoRun 同名时后面的会盖掉前面的 （不会有警告）。用模组名当 Name 就不会撞到别人。
Tag 是“包含”判定，不是“等于” "Tag": "AutoRun,剧情" 也算 AutoRun。大小写不敏感，写 autorun 也认得。

发放角色

"<AddRole>新角色

参数是角色数据表的 Name（不是 Name_I2）。

角色要出现在“回想之境 > 船员”还需要两个条件
  • ID 大于 0
  • Name 不是空的
两个条件不满足时，即使 <AddRole> 执行了也看不到。

发放关卡

两行都不能省。

"<AddStageGroup>模组",
"<AddStage>模组试炼 深渊"
少了 <AddStageGroup> 关卡就看不到 关卡必须挂在一个群组底下。没有群组，玩家在关卡菜单里找不到它。
游戏内建了一个叫“模组”的群组可以直接用。
重复执行是安全的 已经持有的群组和关卡不会被加第二次。

发放道具

"<AddItem>超强药水,1"
道具通常不需要 AutoRun 道具有 SellPrice 这类字段，填了就会出现在商店里让玩家买。 只有“想直接送给玩家”时才需要 <AddItem>。

AutoRun 要注意的一件事

存档停在剧情中间时，AutoRun 会跟那段剧情同时进行 读档时如果刚好续播一段剧情，AutoRun 会跟它抢画面。
建议 AutoRun 只放纯数据指令 —— <AddRole> / <AddItem> / <AddStage> / <Var> 这类。
想写对话和节奏，放到关卡的胜利演出里更自然（见下一章）。
多个模组的 AutoRun 是串行的 一个播完才播下一个，顺序 = 模组管理页的排序（由上而下）。
所以你在 AutoRun 里写 <Wait> 安排节奏时， 不会被别的模组插话。

命名惯例：补既有的演出位

游戏有些地方是用固定名称去找演出的。把 Name 取成那个名字，就会在对应时机被叫到 —— 不需要 Tag。

主画面角色对话

玩家在主画面点角色立绘时播放。名称规则：

主画面角色对话_<角色的 Name>

例如角色的 Name 是“新角色”：

Data/Show/RoomTalk.json

{
  "Name": "主画面角色对话_新角色",
  "Shows": [
    "<Var>主画面对话值,+,1",
    "<if>{主画面对话值}>3",
    "<Var>主画面对话值,=,1",
    "<endif>",
    "<if>{主画面对话值}==1",
    "<MateImage>NewHero",
    "<MateTalk>{目前主画面角色名称}：安安",
    "<elseif>{主画面对话值}==2",
    "<MateTalk>{目前主画面角色名称}：又是你",
    "<elseif>",
    "<MateTalk>{目前主画面角色名称}：没事别乱点",
    "<endif>"
  ]
}
没补这个演出不会报错 模组角色在主画面只会站着不说话。想让他有反应就要补。
用的是角色数据表的 Name，不是翻译后的显示名称。

常用指令速查

指令作用
<AddRole>角色Name给玩家一个角色
<AddItem>道具Name,数量给玩家道具
<AddStageGroup>群组名解锁关卡群组
<AddStage>关卡Name解锁关卡
<Var>变量,=,值设定变量（= / + / -）
<if>条件 … <endif>条件判断，中间可用 <elseif>
<Talk>内容对话。不带内容 = 关掉对话框
<MateTalk>内容主画面对话
<Wait>秒数等待
<BG>背景名,秒数,颜色切背景。<BG>,1 = 淡出
<Image>槽位,角色,表情,服装立绘。不带参数 = 清掉全部
<MateImage>角色,表情,服装主画面立绘（没有槽位参数）
<BGM>音乐名切音乐
<Sfx>音效名播音效
完整的指令列表在演出编辑器里 指令很多，而且有不少参数细节。用演出编辑器 写演出可以边选边看说明，不用背。

对话的写法惯例

说话者写成“名字：内容”：

"<Talk>新角色：早安。"
名字对得上角色数据时会自动上色并打聚光灯 用的是角色数据表的 Name。对不上就只是普通文字，不会报错。

剧情段的开头与结尾

照抄游戏本体的写法：

"<BG>MyBG,0,#00000000",      背景先设好、全透明
"<BG>MyBG,1,#FFFFFF",        1 秒淡入
"<Talk>某人：开场对白。",
"<Talk>",                    关掉对话框
"<Image>",                   清掉立绘
"<BG>,1"                     背景淡出

检查列表

角色 / 关卡加了但玩家看不到：

  1. 有写 AutoRun 演出吗？（最常见原因）
  2. Tag 有含 AutoRun 吗？
  3. <AddRole> 的参数是数据表的 Name 吗？（不是 Name_I2）
  4. 数据的 ID 大于 0 吗？
  5. 关卡有写 <AddStageGroup> 吗？
  6. 回标题重新“开始新游戏”或“读取存档”了吗？

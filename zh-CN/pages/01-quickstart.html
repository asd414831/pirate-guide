快速开始

目标：五分钟内做出一个会动的模组，确认整条流程通了。

1. 找到模组文件夹

模组放在游戏安装目录底下：

<游戏安装文件夹>/Pirate_Data/StreamingAssets/Mods/

最快的找法：进游戏 → 标题画面 → 模组管理 → 开启文件夹。游戏会直接帮你开，不用自己翻。

如果没有 Mods 文件夹 自己建一个就行，名字要正好是 Mods。
如果标题画面连“模组”按钮都没有，代表你的版本不支持模组 —— 手机版和 Demo / 试玩版都没有这个功能。

2. 建立你的模组文件夹

在 Mods/ 底下建一个文件夹。名字自订，建议用英文和数字，避免空格：

Mods/
└── MyFirstMod/
文件夹名称是模组的身份证 游戏用文件夹名记住“这个模组有没有被启用”。
改名字 = 变成另一个模组，启用状态会归零，玩家要重新打开。发布后就不要再改。

3. 写 mod.json

在你的模组文件夹里建一个 mod.json。没有这个档，游戏不会认为那是模组， 连列表都不会出现。

{
  "name": "我的第一个模组",
  "author": "你的名字",
  "version": "1.0",
  "description": "测试用。加了一个超强药水。"
}

所有字段都可以省略，缺了会用默认值。详细说明见 mod.json 字段。

4. 加一笔数据

数据放在 Data/<表名>/ 底下，一个 JSON 档就是一笔数据。 这里加一个道具：

MyFirstMod/
├── mod.json
└── Data/
    └── Item/
        └── SuperPotion.json

SuperPotion.json 的内容：

{
  "Name": "超强药水",
  "Name_I2": "超强药水",
  "Desc": "喝下去会变得很强",
  "Type": "道具",
  "AddHP": 999
}
文件夹名决定改哪张表 Data/Item/ 改的是道具表，Data/Role/ 改角色表。
写 Item 或 TheItem 都会被接受（游戏会自动补上 The）。
文件名不重要，游戏看的是文件里面的 Name 字段。

5. 启用并测试

  1. 回到游戏，标题画面 → 模组管理
  2. 找到“我的第一个模组”，按启用
  3. 回到标题画面，再“开始新游戏”或“读取存档”
  4. 进游戏看道具列表，应该有“超强药水”
改完要回标题重新进入游戏 模组数据在“开始新游戏”与“读取存档”这两个时机合并。 改完文件或切换启用状态后，回到标题画面再进一次游戏就会生效 —— 不需要关掉游戏重开。
已经在进行中的游戏不会即时变动，要回标题再进来。

成功了吗？

看到新道具 → 整条流程通了 接下来看 修改游戏数据，学怎么改既有内容、有哪些字段可以填。
没看到 → 去疑难排解 疑难排解 有错误消息对照表和检查列表。 九成的问题是 JSON 格式打错（少一个逗号、多一个逗号）。

完整的模组长什么样

一个用到全部功能的模组结构：

MyMod/
├── mod.json              名片档（必要）
├── icon.png              列表缩略图（选配）
├── Data/                 数据表
│   ├── Item/
│   │   └── SuperPotion.json
│   ├── Role/
│   │   └── NewHero.json
│   └── Skill/
│       └── MegaSlash.json
├── Images/               图片
│   ├── RoleHead/
│   │   └── NewHero.png
│   └── Role/
│       └── NewHero.png
└── Music/                音乐与音效
    ├── BGM/
    │   └── BGM_MyTheme.ogg
    └── Sfx/
        └── se_MyHit.ogg

各部分的详细规则在后面的章节。

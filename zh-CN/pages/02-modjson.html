mod.json 字段

模组的名片档。决定玩家在模组列表里看到什么。

放哪里

Mods/<你的模组文件夹>/mod.json
没有 mod.json = 不是模组 游戏扫描 Mods/ 时，只把“含有 mod.json 的子文件夹”当成模组。 少了这个档，你的文件夹会被完全忽略，连列表都不会出现（也不会有错误消息）。

完整示例

{
  "name": "更难的海盗",
  "author": "某位玩家",
  "version": "1.2.0",
  "description": "敌人变强，掉落变少。\n适合二轮以后游玩。",
  "icon": "icon.png"
}

字段表

字段型别缺少时说明
name文字用文件夹名 模组列表显示的名称。可以用任何语言。
author文字显示“未知作者” 你的名字或昵称。
version文字显示“-” 纯显示用。游戏不会比较版本大小，写 1.0 或 v2-beta 都行。
description文字空白 说明。可以换行，用 \n。
icon文字icon.png 缩略图的相对路径。文件不存在时显示默认底图。
所有字段都可以省略 连空的 {} 都能运作 —— 游戏会用文件夹名当显示名称。 少写一个字段不会让模组坏掉，这是刻意的设计。

缩略图

默认会找模组文件夹底下的 icon.png。想换文件名或放子文件夹：

{
  "icon": "art/my-thumbnail.png"
}

路径是相对于模组文件夹，不是相对于 Mods/。

换行怎么写

JSON 的字符串不能直接按 Enter 换行，要用 \n：

{
  "description": "第一行\n第二行\n\n空一行后的第三行"
}
Windows 路径的反斜线要跳脱 JSON 里 \ 是特殊字元。icon 路径请用正斜线 art/icon.png，不要写 art\icon.png。 真的要写反斜线得打两个 \，很容易出错，不建议。

写坏了会怎样

如果 mod.json 存在但格式错误（少逗号、多逗号、引号没关）， 模组还是会出现在列表里，但会被标记为坏掉。

格式写坏的模组不会消失，会列在那里标成坏的。因为直接消失的话你只会觉得 “文件放错地方了吗”然后找一小时。

常见的 JSON 错误：

{
  "name": "我的模组",
  "author": "某人",     <-- 最后一个字段不能有逗号
}

{
  "name": "我的模组"
  "author": "某人"      <-- 中间的字段漏了逗号
}

{
  'name': '我的模组'    <-- JSON 只能用双引号，不能用单引号
}
用 VS Code 编辑可以避开九成问题 它会即时标红格式错误。或者把文件内容贴到任何线上 JSON 检查工具验一次。

文件夹名不要改

启用状态绑在文件夹名上，不是 name 字段 游戏用文件夹名记住玩家有没有启用这个模组。
改 mod.json 的 name：安全，只是显示名称变了。
改文件夹名：对游戏来说变成另一个模组，启用状态归零，玩家要重新打开。 发布之后就不要再改文件夹名。

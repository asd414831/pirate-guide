海盗 模组制作手册

不用写程序。会用记事本，就能做模组。

这份手册教你怎么帮《海盗》做模组 —— 加新道具、改角色数值、换立绘、放自己的 BGM。 全部靠编辑文字档完成，不需要任何开发工具，也不需要重新编译游戏。

五分钟就能做出第一个模组 建一个文件夹、写一个 mod.json、放一个 JSON 档。就这样。 直接跳到 快速开始。

你可以做什么

  • 改数值 —— 角色、敌人、技能、Buff、道具、关卡、地形…游戏的 13 张数据表全部可改
  • 加新内容 —— 不只是改既有的，可以凭空加新道具 / 新角色 / 新技能
  • 带自己的美术 —— PNG 放进 Images/ 就会被加载，可以加新立绘或换掉本体素材
  • 带自己的音乐 —— OGG / MP3 / WAV 放进 Music/，BGM 和音效都支持
  • 做整套战斗内容 —— 自订敌人、敌人 AI、多波次关卡、战斗背景
  • 写剧情演出 —— 对话、立绘、表情差分、关卡的开场与结局

你不能做什么

  • 删除既有内容 —— 模组只能“改”和“加”，没有删除功能。想隐藏东西要用 UnlockCon（见 修改游戏数据）
  • 加新程序逻辑 —— 不能写 C#。但剧本指令和演出系统的组合已经很自由
  • 在手机版使用 —— 模组功能是桌机版限定

章节

需要准备什么

用途工具说明
编辑 JSON记事本 / VS Code / Notepad++任何纯文字编辑器都行。推荐 VS Code，会帮你检查 JSON 格式
做图任何绘图软件输出 PNG 即可
做音乐任何音讯软件输出 OGG / MP3 / WAV
做剧情演出演出编辑器视觉化工具，见 演出编辑器
这份手册的内容是跟着游戏程序走的 里面写的规则（合并方式、文件夹结构、优先级）都对照实际实作。 如果你发现手册跟游戏行为不一致，那是手册过时了 —— 请回报。

mod.json 필드

모드의 신분증입니다. 이것은 플레이어가 모드 목록에서 무엇을 볼지 결정합니다.

저장 위치

Mods/<your mod folder>/mod.json
mod.json이 없다는 것은 그것이 모드가 아님을 의미합니다스캔할 때Mods/, 게임은 하위 폴더만 처리합니다포함하는mod.json모드로서. 이것이 없으면 폴더가 완전히 무시됩니다 — 목록에 나타나지 않으며, 오류 메시지도 없습니다.

전체 예시

{
  "name": "Harder Pirates",
  "author": "Some Player",
  "version": "1.2.0",
  "description": "Enemies hit harder, drops are rarer.\nMeant for new game plus.",
  "icon": "icon.png"
}

필드 참조

필드타입생략된 경우설명
name텍스트폴더 이름이 사용됩니다모드 목록에 표시되는 이름. 어떤 언어든 가능.
author텍스트"알 수 없는 저자"라고 표시됨당신의 이름 또는 닉네임.
version텍스트“-”를 보여줍니다디스플레이 전용. 게임절대버전을 비교합니다 —1.0또는v2-beta둘 다 괜찮습니다.
description텍스트비어 있음설명. 사용\n줄 바꿈용.
icon텍스트icon.png썸네일에 대한 상대 경로. 파일이 없으면 기본 이미지로 대체됩니다.
모든 필드는 선택 사항입니다비어 있는 것조차{}작동 — 게임은 폴더 이름으로 되돌아갑니다. 필드를 생략해도 모드를 깨뜨리지 않습니다. 이것은 의도된 것입니다.

썸네일

기본적으로 게임은 찾습니다icon.png모드 폴더 안에. 다른 이름이나 하위 폴더를 사용하려면:

{
  "icon": "art/my-thumbnail.png"
}

경로는 ~에 상대적입니다당신의 모드 폴더, ~가 아니라Mods/.

줄 바꿈

JSON 문자열은 실제 줄바꿈 문자를 포함할 수 없습니다 — 사용하십시오\n:

{
  "description": "First line\nSecond line\n\nThird line after a blank one"
}
Windows 경로에서 백슬래시를 이스케이프하기\JSON에서 특별한 문자입니다.슬래시를 사용하세요위한icon경로 —art/icon.png, 아니art\icon.png. 실제 백슬래시는 두 번 입력해야 합니다 ("\\), 잘못 이해하기 쉬운 부분입니다.

형식이 올바르지 않을 때

만약mod.json존재하지만 구문 오류가 있습니다(쉼표 누락, 쉼표 과잉, 닫히지 않은 따옴표),모드가 여전히 목록에 나타나지만 손상된 것으로 표시됩니다.

그건 의도적인 거야만약 깨진 모드가 단순히 사라진다면, 플레이어들은 파일이 잘못된 위치에 있다고 가정하고 조사할 방법이 없을 것입니다. 목록에 올리고 플래그를 표시하면 '거기에 있지만 뭔가 문제가 있다'고 알려주는 셈입니다.

일반적인 JSON 실수:

{
  "name": "My Mod",
  "author": "Someone",     <-- trailing comma on the last field
}

{
  "name": "My Mod"
  "author": "Someone"      <-- missing comma between fields
}

{
  'name': 'My Mod'         <-- JSON requires double quotes
}
VS 코드에서 편집하면 이러한 것들의 거의 9할을 피할 수 있습니다입력하는 동안 구문 오류를 강조 표시합니다. 또는 파일을 온라인 JSON 검증기에 붙여넣을 수도 있습니다.

폴더 이름을 바꾸지 마세요

활성 상태는 폴더 이름에 연결되어 있으며, 그에 연결되지 않습니다name필드변경 중name안에mod.json: 안전하며, 표시 이름만 변경됩니다.
변경 중폴더 이름: 게임에 관해서는 다른 모드입니다 — 활성화 상태가 초기화되며 플레이어가 다시 켜야 합니다. 출시 후 이름을 바꾸지 마세요.

게임 데이터 편집

모드가 하는 주요한 일. 기존 값을 바꾸거나, 새로운 콘텐츠를 추가하는 것.

기본 규칙

Mods/<your mod>/Data/<table>/<any filename>.json
  • 폴더 이름이 테이블을 선택합니다—Data/Item/항목을 편집합니다,Data/Role/문자를 편집합니다
  • 하나의 JSON 파일은 하나의 항목입니다— 파일당 하나의 항목; 여러 항목을 하나의 파일에 넣지 마세요
  • 파일 이름은 상관없다— 게임이 읽습니다Name필드 내부. 파일 이름은 오로지 여러분 자신의 편의를 위한 것입니다
둘 다Item그리고TheItem일내부 테이블 이름은TheItem; 폴더가 호출될 때Item그 게임은 맨 앞에 추가한다The자동으로. 두 가지 철자 모두 허용됩니다 — 실수할 일이 하나 줄어듭니다.

병합 규칙 (중요한 부분)

게임은 이미 전체 데이터 세트를 가지고 있습니다. 당신의 JSON은위에 겹쳐진, 교체하지 않고. 일치시키는 데 사용되는 키는Name필드:

당신의Name결과
그 게임이미 가지고 있다그 이름제자리에서 편집됨.작성한 필드만 변경됩니다; 나머지 모든 것은 원래 값을 유지합니다
그 게임가지고 있지 않다그것목록 끝에 새 항목으로 추가됨
변경하려는 필드만 작성하세요상품을 더 높은 가격에 판매하려면, 전체 파일은 두 줄입니다:
{ "Name": "Herb", "SellPrice": 500 }
나머지 모든 것(이름, 아이콘, 효과)은 손대지 않았습니다.
삭제가 없습니다모드는 기존 게임 콘텐츠를 제거할 수 없습니다. 어떤 것을 나타나지 않게 하려면 설정하세요UnlockCon결코 참이 되지 않는 조건에 대해서는 삭제하려고 하지 마세요.

Name은 항목의 식별자입니다

에 오타Name편집을 추가로 바꾼다만약 당신이 'Herb'를 편집하려다가 'Herbb'라고 썼다면, 게임은 불평하지 않습니다 — 그것은 당신이 원한다고 가정합니다추가하다“Herbb”라는 새로운 아이템. 결과: 원래의 허브는 변경되지 않았고 이상한 새로운 아이템이 생겼다.
모더레이터가 아무것도 하지 않을 때,확인Name먼저 오타를 확인하기(띄어쓰기 및 전각 문자를 포함하여).

필드 이름 찾기

필드 이름은 대소문자를 포함하여 게임 내부 구조와 정확히 일치해야 합니다. 가장 신뢰할 수 있는 조회 방법은연출 편집기에서 데이터 테이블 보기(보기연출 편집기), 모든 테이블의 모든 필드를 나열합니다.

아니면 그냥 일부러 오타를 내세요필드 이름이 존재하지 않을 때, 게임은 제안을 출력합니다:
TheItem has no field "IconImage", skipped. Did you mean "IconName"?
찾아보는 것보다 빠르다.

콘텐츠를 추가하려면 ID가 필요합니다

새 항목에는 반드시ID0보다 크거나 그렇지 않으면 건너뜁니다다음 항목 포함ID0 또는 음수는 스프레드시트의 자리 표시자 행으로 처리되며 게임에는 절대 나타나지 않습니다.
9000 이상 사용게임 자체가 나중에 추가할 수 있는 콘텐츠를 피하기 위해.
기존 항목을 편집할 때는 필요하지 않습니다ID전혀 — 원본이 유지됩니다.

자료형: 따옴표 사용 기준

JSON은 숫자와 텍스트를 다르게 작성하며, 게임의 필드 유형과 일치해야 합니다.

{
  "Name": "SuperPotion",
  "SellPrice": 500,          number, no quotes
  "AddHP": 999,              number, no quotes
  "Name_I2": "Super Potion", text, quotes
  "Atk": "20"                text, quotes (see below)
}
장비 능력치 필드는 숫자가 아니라 텍스트입니다Atk/MaxHP/AtkPercent그리고 친구들이 잡다수식 문자열, 그러므로 쓰다"Atk": "20", 아니"Atk": 20.
이것이 스탯이 레벨에 따라 확장되도록 하는 것입니다. 필드에 따옴표가 필요한지 확실하지 않을 때는,게임 자체의 같은 종류 데이터가 어떻게 작성되어 있는지 살펴보세요그리고 그것을 복사하세요.

필드 목록

일부 필드는 여러 값을 가질 수 있으며, JSON에서는 배열입니다:

{
  "Name": "SomeCharacter",
  "Skill": ["Slash", "Heavy Slash", "Spin Slash"]
}
배열은 전체 목록을 대체합니다; 추가하지 않습니다그렇게 쓰여진 대로, 그 캐릭터는바로 그 세 가지 기술— 원본은 사라졌습니다.
기존 것을 유지하고 더 추가하기 위해,기존 항목들도 나열하세요.
왜 붙이지 않나요: 같은 패치를 두 번 적용하면, 붙이면 결과가 나옵니다["Slash","Heavy Slash","Slash","Heavy Slash"]. 대체는 예측 가능한 행동입니다.

쉼표로 구분된 필드

일부 필드는 내부적으로 단일 쉼표로 구분된 문자열(item)로 저장됩니다Tag, 예를 들어). 두 형태 모두 작동하며 같은 의미를 갖습니다:

"Tag": "Usable in battle,Fruit"
"Tag": ["Usable in battle", "Fruit"]

예시: 기존 항목을 편집하기

Data/Item/HerbPrice.json

{
  "Name": "Herb",
  "SellPrice": 500
}

판매 가격만 변경됩니다. 다른 것은 건드리지 않습니다.

예시: 항목 추가

Data/Item/SuperPotion.json

{
  "Name": "SuperPotion",
  "Name_I2": "Super Potion",
  "Desc": "Drink it and you get very strong",
  "Type": "Item",
  "IconName": "Potion",
  "SellPrice": 1000,
  "AddHP": 999,
  "AddMP": 99
}
IconName게임 자체의 아트를 빌릴 수 있다기존 아이콘의 이름을 지정하면 해당 이미지가 사용됩니다. 직접 만든 작품을 제공하려면 다음을 참조하세요이미지 추가.

예시: 적을 더 강하게 만들기

Data/Enemy/SlimeBuff.json

{
  "Name": "Slime",
  "MaxHP": "200",
  "Atk": "30"
}

현지화

이 게임은 번체 중국어, 간체 중국어, 영어, 일본어, 한국어 및 러시아어를 지원합니다. 이름 및 설명 필드는 끝에_I2번역 시스템에 입력하다.

생략Name_I2이름을 비워 둔다Name단지 내부 식별자일 뿐 —플레이어가 보는 것은Name_I2. 설정만Name게임에서 이름과 설명이 비어 있는 항목을 제공하며, 오류 메시지는 나타나지 않습니다.
현지화하지 않더라도,항상 작성하세요Name_I2— 그냥 자신의 언어를 넣으세요.
문자열을 구두점으로 끝내지 마세요번역 시스템은 뒤따르는 구두점을 구분자로 처리하여 조회가 실패하게 만듭니다.
쓰다"Deals heavy damage", 아니"Deals heavy damage."
문장 중간의 쉼표도 일반 공백으로 바꾸는 것이 가장 좋습니다.

적용 순서

모드 데이터는 게임 시작 시 적용됩니다:

  1. 게임이 자체 데이터를 불러옵니다
  2. 모드는 순서대로 겹쳐져 적용됩니다(나중 모드가 이전 모드를 덮어씁니다)

모드는 항상 최상위 레이어이므로, 당신의 변경 사항은 항상 적용됩니다. 모드 간의 충돌은 다음을 참조하세요여러 모드.

편집 후 타이틀 화면에서 게임에 다시 들어가기데이터가 병합되는 기준새 게임 시작그리고게임 불러오기. 제목으로 돌아가서 다시 입력하세요 —게임을 다시 시작할 필요가 없습니다진행 중인 세션은 변경되지 않습니다.

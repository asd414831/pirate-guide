빠른 시작

목표: 5분 안에 작동하는 모드를 만들어 전체 파이프라인이 돌아가는지 확인하는 것.

1. 모드 폴더를 찾기

모드는 게임 설치 디렉터리 아래에 있습니다:

<game install folder>/Pirate_Data/StreamingAssets/Mods/

거기에 가는 가장 빠른 방법:게임 실행 → 타이틀 화면 → 모드 관리자 → 폴더 열기. 게임이 그것을 열어 줍니다.

Mods 폴더가 없으면그냥 하나 만드세요 — 정확히 같은 이름이어야 합니다Mods.
타이틀 화면에 Mod Manager 버튼이 전혀 없으면, 당신의 빌드는 모드를 지원하지 않습니다 — 모바일 및 데모 빌드에는 이 기능이 없습니다.

2. 모드 폴더를 만드세요

안에 폴더를 만들기Mods/. 마음대로 이름을 지으세요; 영어 알파벳과 숫자가 가장 안전하며, 공백은 피하세요:

Mods/
└── MyFirstMod/
폴더 이름은 모드의 정체성입니다게임은 폴더 이름으로 '이 모드가 활성화되어 있는지'를 기억합니다.
이름을 바꾸면 다른 모드가 됩니다— 활성화 상태가 재설정되며 플레이어가 다시 켜야 합니다. 출시 후에는 이름을 변경하지 마세요.

3. mod.json 작성하기

만들다mod.json모드 폴더 안에.이 파일이 없으면 게임에서는 이것을 모드로 간주하지 않습니다— 목록에도 나타나지 않을 거예요.

{
  "name": "My First Mod",
  "author": "Your Name",
  "version": "1.0",
  "description": "Testing. Adds an absurdly strong potion."
}

모든 필드는 선택 사항이며 기본값으로 돌아갑니다. 자세한 내용은mod.json 필드.

4. 데이터 한 개 추가

데이터가 아래로 간다Data/<table>/, 그리고하나의 JSON 파일은 하나의 항목입니다. 아이템이 있습니다:

MyFirstMod/
├── mod.json
└── Data/
    └── Item/
        └── SuperPotion.json

의 내용SuperPotion.json:

{
  "Name": "SuperPotion",
  "Name_I2": "Super Potion",
  "Desc": "Drink it and you get very strong",
  "Type": "Item",
  "AddHP": 999
}
폴더 이름이 어떤 테이블을 편집할지 결정합니다Data/Item/항목을 편집합니다,Data/Role/문자를 편집합니다.
둘 다Item그리고TheItem허용됩니다(게임이 앞에 추가됩니다The너를 위해).
파일 이름은 상관없다— 게임이 읽습니다Name파일 안의 필드.

5. 활성화하고 테스트하세요

  1. 다시 게임으로 돌아왔다,타이틀 화면 → 모드 관리자
  2. "My First Mod"을 찾아서 누르세요활성화
  3. 제목 화면으로 돌아간 다음 새 게임을 시작하거나 게임을 불러오세요
  4. 가게를 확인하세요 — "슈퍼 포션"이 거기에 있어야 합니다
변경 사항은 타이틀 화면에서 게임에 다시 들어갈 때 적용됩니다모드 데이터는 두 시점에서 병합됩니다:새 게임 시작그리고게임 불러오기 파일을 편집하거나 모드를 전환한 후에는 타이틀 화면으로 돌아가서 다시 들어가세요 —게임을 다시 시작할 필요가 없습니다.
이미 진행 중인 세션은 변경되지 않습니다. 타이틀 화면으로 돌아가야 합니다.

정상적으로 작동했나요?

새 항목을 확인하세요 → 전체 파이프라인이 작동합니다다음으로, 읽으세요게임 데이터 편집기존 콘텐츠를 어떻게 수정하는지와 어떤 필드가 있는지를 배우기 위해.
보이지 않으면 → 문제 해결로 이동문제 해결오류 메시지 표가 있으며 증상별로 확인합니다. 대개 열에 아홉 번은 JSON 구문 오류(콤마 누락 또는 과다)입니다.

완성된 모드의 폴더 구조

모든 기능을 사용하는 모드:

MyMod/
├── mod.json              ID card (required)
├── icon.png              list thumbnail (optional)
├── Data/                 data tables
│   ├── Item/
│   │   └── SuperPotion.json
│   ├── Role/
│   │   └── NewHero.json
│   └── Skill/
│       └── MegaSlash.json
├── Images/               artwork
│   ├── RoleHead/
│   │   └── NewHero.png
│   └── Role/
│       └── NewHero.png
└── Music/                audio
    ├── BGM/
    │   └── BGM_MyTheme.ogg
    └── Sfx/
        └── se_MyHit.ogg

각 부분은 다음 장에서 다룹니다.

오디오 추가

모드 제작자는 자신의 음악과 음향 효과를 탑재할 수 있습니다.

기본 규칙

Mods/<your mod>/Music/<any subfolder>/<name>.ogg
항목세부 사항
지원되는 형식OGG / MP3 / WAV
추천OGG— 작고, 로딩이 빠르며, 라이선스 문제가 없음
하위 폴더원하는 대로 정리하세요;그들은 조회에 영향을 미치지 않습니다

경로를 제외한 파일 이름만 사용합니다

이것은 이미지의 반대이며, 혼동하기 쉽습니다오디오 하위 폴더는순전히 귀하의 조직을 위해; 조회는 파일 이름만 사용합니다.
Music/BGM/MyTheme.ogg그리고Music/whatever/nested/MyTheme.ogg있다동일한게임에 관해서라면 둘 다 "MyTheme"입니다.

그래서 이 두 레이아웃은 동일하게 작동합니다:

Music/
├── BGM/
│   └── MyTheme.ogg          → the game knows it as "MyTheme"
└── Sfx/
    └── se_MyHit.ogg         → the game knows it as "se_MyHit"
Music/
├── MyTheme.ogg              → still "MyTheme"
└── se_MyHit.ogg             → still "se_MyHit"
다른 폴더에 같은 파일 이름 = 그 중 하나가 사라짐조회는 파일 이름만 사용하기 때문에,Music/BGM/Theme.ogg그리고Music/Sfx/Theme.ogg충돌하고 단 한 사람만 이긴다.
자신의 파일에 접두사를 붙이세요 (BGM_,se_) 그것을 피하기 위해.

BGM 트랙 추가하기

두 단계. 어느 하나라도 놓치면 소리가 나지 않는다.

1. 오디오 파일을 드롭하세요

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. 그것을 BGM 목록에 등록하세요

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "Description of the track",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "Composer name"
}
파일 없이 등록하거나, 등록 없이 파일을 하면 둘 다 조용히 실패합니다
  • 파일 전용 → 게임에서는 거의 참조되지 않음
  • 등록만 가능 → 이름이 목록에 나타나지만아무 것도 연주하지 않는다
어느 경우도 오류 메시지를 생성하지 않습니다.
ID0보다 커야 하며, 그렇지 않으면 목록에 표시되지 않습니다다음 항목 포함ID0 또는 음수는 자리 표시자 행으로 취급됩니다.
나중에 게임이 추가할 수 있는 콘텐츠를 피하려면 9000 이상을 사용하세요.
다른 필드들
  • Name— 오디오 파일 이름과 일치해야 함 (없이.ogg)
  • Desc— 설명 텍스트
  • Path— 표시용만; 파일 이름이면 충분합니다
  • Maker— 작곡가
뮤직 갤러리 항목은 잠겨서 시작됩니다트랙이 게임에서 실제로 처음 재생될 때 자동으로 잠금이 해제됩니다. 추가 설정은 필요 없습니다.

게임의 음악 교체

사용하다같은 파일 이름원본과 동일하게. 등록 필요 없음 — 게임이 이미 등록했습니다:

Music/BGM_Title.ogg      <-- replaces the title screen music
모드 오디오는 게임 오디오보다 우선합니다이미지와 같은 규칙입니다. 전체 사운드트랙을 교체하는 모드는 완전히 가능합니다.

음향 효과

이펙트는 동일한 폴더에 있으며 동일한 규칙을 따릅니다. 유일한 차이점은그들은 등록할 필요가 없다— 기술과 참조를 이름으로 표시합니다.

Music/Sfx/se_MyHit.ogg

그다음에 기술이나 공연이 진행된다se_MyHit.

로딩 시간 (중요)

오디오는 백그라운드에서 로드됩니다; 시작 후 처음 몇 초 동안은 준비되지 않습니다이미지와 달리 오디오(특히 MP3)는 디코딩하는 데 시간이 걸립니다. 게임에서 하는 것은 다음과 같습니다:
시작 시 어떤 파일이 있는지 기록하십시오(빠르게), 그런 다음백그라운드에서 그것들을 디코딩하다.
따라서 실행 직후 처음 몇 초 동안 모드 오디오를 재생하면 무음이나 게임의 원래 트랙이 나올 수 있습니다. 잠시 후에 다시 시도하면 괜찮습니다.
버그가 아니며, 우회할 필요도 없습니다실제 플레이에서는 아무도 첫 초에 모드 음악 장면에 도달하지 않습니다. 하지만 직접 테스트에서 '첫 번째에는 소리가 나지 않지만, 두 번째에는 괜찮다'고 나오면, 이것이 그 이유입니다.
한 가지 예외는 그것을 교체하는 것입니다타이틀 화면BGM — 그 순간은 아직 로딩 중일 수 있으므로, 로딩이 끝나면 게임이 이를 한 번 재생합니다.
MP3는 작동하지만 OGG가 더 안전합니다MP3 디코더 지원은 환경마다 다릅니다. 실패할 경우 게임은 경고를 기록합니다 (조용히 실패하지 않습니다). OGG는 Unity의 기본 형식이며 가장 안정적입니다.

파일 크기 안내

사용하다추천된왜
배경 음악OGG, 2–5 MB루핑 트랙은 OGG로 압축할 때 가장 좋습니다
음향 효과OGG 또는 WAV, < 500 KB짧은 효과는 WAV일 수 있습니다; 이것이 가장 빠르게 디코딩됩니다
피하다큰 WAVWAV BGM은 50MB 이상일 수 있으며, 로딩이 느리고 낭비적입니다

체크리스트

소리가 없을 때, 순서대로:

  1. 파일이 아래에 있습니까Music/?
  2. OGG / MP3 / WAV 인가요? (실제로 변환된 것이지, 이름만 바뀐 것은 아니죠)
  3. BGM의 경우, 등록되어 있나요Data/BGM/?
  4. 등록된 것Name파일 이름과 정확히 일치합니까 (확장자 제외)?
  5. 이다ID0보다 큰가?
  6. 파일 이름이 다른 오디오 파일과 충돌합니까?
  7. 출시 직후 너무 빨리 테스트해 보셨나요? (몇 초 기다리세요)
  8. 타이틀 화면으로 돌아가 새 게임을 시작했나요, 아니면 게임을 불러왔나요?
라이선스 관리는 귀하의 책임입니다모드를 배포할 때는 오디오를 배포할 권리가 있는지 확인하세요. 다른 사람의 작업물에 대해서는 허가를 받거나, 명확히 자유롭게 사용할 수 있는 자료를 사용하세요.

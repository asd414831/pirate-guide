해적 모드 제작 가이드

프로그래밍이 필요 없습니다. 텍스트 편집기를 사용할 수 있다면 모드를 만들 수 있습니다.

이 가이드는 모드 제작에 대해 다룹니다해적— 아이템 추가, 캐릭터 능력치 변경, 아트워크 교체, 직접 음악 추가. 모든 것은 텍스트 파일을 편집하여 이루어집니다. 개발 도구도, 게임 재컴파일도 필요 없습니다.

당신의 첫 번째 모드는 5분 걸립니다폴더를 만들고, 하나 작성하세요mod.json, 하나의 JSON 파일에 넣으세요. 그게 다입니다. 바로 이동빠른 시작.

할 수 있는 작업

  • 값 변경— 캐릭터, 적, 스킬, 버프, 아이템, 스테이지, 지형… 게임의 13개 데이터 테이블 모두 편집 가능합니다
  • 새로운 콘텐츠 추가— 기존의 것을 편집하는 것뿐만 아니라, 완전히 새로운 아이템, 캐릭터, 스킬을 추가할 수도 있습니다
  • 직접 만든 이미지를 추가하세요— PNG 파일을 여기에 드롭Images/그리고 그것들을 불러옵니다; 새로운 초상화를 추가하거나 게임 자체의 것을 교체합니다
  • 직접 만든 오디오를 추가하세요— OGG / MP3 / WAV 안에Music/배경 음악과 효과음 모두
  • 전체 전투를 구성하세요— 맞춤형 적, 적 AI, 다중 웨이브 스테이지, 전투 배경
  • 스토리 장면을 작성하세요— 대화, 초상화, 표정 변형, 스테이지 도입부 및 엔딩

지원하지 않는 작업

  • 기존 내용 삭제— 모드는 오직 변경하고 추가할 수 있습니다. 무언가를 숨기려면, 사용하세요UnlockCon(보기게임 데이터 편집)
  • 새 프로그램 로직 추가— C#는 없지만, 스크립트 명령과 연출 시스템은 이미 꽤 융통성이 있습니다
  • 모바일에서 모드 사용하기— 데스크톱 전용

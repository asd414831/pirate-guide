加入圖片

模組可以帶自己的美術。放進 Images/ 就會被載入。

基本規則

Mods/<你的模組>/Images/<照抄遊戲的結構>/<圖名>.png
照抄遊戲本體的資料夾結構就對了 不需要記任何特殊規則。遊戲裡角色頭像放在 RoleHead/， 你的模組也放 Images/RoleHead/。就這樣。

範例

MyMod/
├── mod.json
├── Data/
│   └── Role/
│       └── NewHero.json
└── Images/
    ├── RoleHead/
    │   └── NewHero.png      角色頭像
    └── Role/
        └── NewHero.png      角色立繪

資料夾對照表

資料夾內容資料表欄位
Images/Role/立繪（角色與敵人共用）PSB
Images/RoleHead/頭像ImageName / EyeImageName
Images/Icon/道具與 buff 圖示IconName
Images/Background/背景圖FightBackground、劇本 <BG>
Images/Sticker/貼紙小圖劇本 <Sticker>
IconName 要含子路徑 圖示放 Images/Icon/Buff/MyIcon.png 時， IconName 填 "Icon/Buff/MyIcon"。
其他欄位（PSB / ImageName）只填檔名就好。

然後在 Data/Role/NewHero.json 裡指定圖名：

{
  "Name": "新角色",
  "Name_I2": "新角色",
  "ImageName": "NewHero"
}
圖名不含資料夾也不含 .png 放的是 Images/RoleHead/NewHero.png， 資料裡填的是 "NewHero"。遊戲自己知道要去哪個資料夾找。

格式

項目要求
檔案格式PNG
透明背景支援（頭像和立繪通常需要）
尺寸沒有硬性限制，但建議跟本體同類型的圖一致，不然會顯示得太大或太小
尺寸怎麼抓 去看遊戲本體同類型的圖多大，照著做。角色立繪跟道具圖示的尺寸差很多， 用錯會在遊戲裡看起來很奇怪（不會壞，只是難看）。

覆蓋本體的圖

用跟本體一樣的路徑和檔名，就會蓋掉本體那張。

Images/RoleHead/主角.png      <-- 換掉主角的頭像
模組圖優先於本體圖 這是刻意的設計 —— 想做「換立繪」「換 UI 風格」的模組應該辦得到。 不需要任何額外設定，同名就會蓋掉。
檔名要完全一致，包含中文字 本體的圖如果叫 主角.png，你的檔名也得是 主角.png。 差一個字（或全形半形不同）就不會覆蓋，而是變成一張沒人用的新圖。

立繪的表情與服裝差分

立繪有兩種擺法，看你要不要差分。

(A) 不要差分 —— 一張圖到底

Images/Role/Nausea.png

(B) 要差分 —— 改放成資料夾

Images/Role/Nausea/Body/Body_Normal.png
Images/Role/Nausea/Body/Body_Dark.png
Images/Role/Nausea/Face/Face_Normal.png
Images/Role/Nausea/Face/Face_Laugh.png
這是最常犯的錯 很多人以為表情圖只要畫「一張臉」那麼大。不是 —— 表情圖也要是全身尺寸的畫布，臉以外全部透明。
裁切成小圖的話，疊上去會出現在左上角。

換服裝也是同一套機制

規則說明
資料夾名 = 群組名目前有 Body（身體 / 服裝）與 Face（表情）兩種
檔名 = 圖層名要自己加 Body_ / Face_ 前綴
每張都是全身圖完整尺寸、背景透明、全部同樣大小
疊圖順序同座標直接疊起來，Face 疊在 Body 之上
每張差分圖都要畫成「完整尺寸的全身圖」 引擎是把它們同座標疊起來，不是把表情貼到臉的位置。
所以表情圖也要是全尺寸、只有臉的部分有內容、其他透明。 不需要（也無法）設定表情的位置。

預設顯示哪一張

情況結果
群組裡有 <群組>_Normal預設顯示它
群組裡沒有 Normal該群組預設全部不顯示

例如只放了 Face_Laugh.png，平常就是沒表情，等劇本叫它才出現。

建議一定要放 Face_Normal.png 「回想之境 > 船員」點進立繪可以翻看所有表情差分， <群組>_Normal 固定排在第一頁 —— 那就是玩家點進去先看到的那一張。
沒有額外表情時，把 Face_Normal.png 畫成全透明就好 （Body 圖本身已經有臉）。
表情頁的排序 頁序是檔名字母序，但 Normal 一定第一頁。
想多一頁「刻意的無表情」，照本體慣例放 Face_Null.png（全透明）—— 名字含 Null 的表情會被固定排到最後一頁。

劇本怎麼切換差分

<Image> 的第 1 段是「槽位」，不是角色名 槽位有 Mid / Left / Right。 角色名從第 2 段才開始。 
<Image>Mid,Nausea,Laugh        臉換成 Face_Laugh
<Image>Mid,Nausea,,Dark        身體換成 Body_Dark
<Image>Mid,Nausea,Laugh,Dark   兩個一起換
<Image>Mid,Nausea,-            該群組全部關掉
<Image>Mid                     清掉該槽的立繪
<Image>                        清掉三個槽

表情和服裝都省略前綴 —— 寫 Laugh 不是 Face_Laugh。

另外兩個同族指令沒有槽位參數，直接從角色名開始：

<MateImage>Nausea,Laugh        主畫面立繪
<EnemyImage>艾瑪,Emma,Shock    戰鬥中換敵人立繪
<EnemyImage> 的第 1 段是敵人的資料 Name 第 2 段起才是「PSB名,表情,服裝」。
找不到指定的差分時 遊戲會提示（例「群組【Face】找不到【Face_Angry】」）， 畫面上那個群組會變成全部不顯示。

子資料夾的意義

跟音樂不同，圖片的資料夾結構有意義：

Images/RoleHead/Nausea.png    <-- 頭像
Images/Role/Nausea.png        <-- 立繪

這兩張是不同的圖，遊戲會分別去對應資料夾找。放錯資料夾 = 找不到。

這點跟音樂剛好相反 音樂的子資料夾純粹給你整理用，不影響查找。 圖片的子資料夾是查找路徑的一部分，不能亂放。

記憶體

所有圖在開機時全部載入並常駐 幾張到幾十張沒問題。如果你的模組有上百張高解析度圖， 玩家的記憶體用量會明顯上升 —— 這是你自己的取捨。

檢查清單

圖沒出現的時候按順序檢查：

  1. 檔案是 .png 嗎？（不是 .jpg 改名）
  2. 放在 Images/ 底下嗎？（不是 Image/，有 s）
  3. 子資料夾名對嗎？（RoleHead 不是 Rolehead）
  4. 資料裡的 ImageName 跟檔名一致嗎？（不含 .png）
  5. 用差分資料夾的話，檔名有加 Body_ / Face_ 前綴嗎？
  6. 差分圖都是同樣尺寸的全身圖嗎？
  7. 回標題重新「開始新遊戲」或「讀取存檔」了嗎？

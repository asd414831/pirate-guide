mod.json 欄位

模組的名片檔。決定玩家在模組列表裡看到什麼。

放哪裡

Mods/<你的模組資料夾>/mod.json
沒有 mod.json = 不是模組 遊戲掃描 Mods/ 時，只把「含有 mod.json 的子資料夾」當成模組。 少了這個檔，你的資料夾會被完全忽略，連列表都不會出現（也不會有錯誤訊息）。

完整範例

{
  "name": "更難的海盜",
  "author": "某位玩家",
  "version": "1.2.0",
  "description": "敵人變強，掉落變少。\n適合二輪以後遊玩。",
  "icon": "icon.png"
}

欄位表

欄位型別缺少時說明
name文字用資料夾名 模組列表顯示的名稱。可以用任何語言。
author文字顯示「未知作者」 你的名字或暱稱。
version文字顯示「-」 純顯示用。遊戲不會比較版本大小，寫 1.0 或 v2-beta 都行。
description文字空白 說明。可以換行，用 \n。
icon文字icon.png 縮圖的相對路徑。檔案不存在時顯示預設底圖。
所有欄位都可以省略 連空的 {} 都能運作 —— 遊戲會用資料夾名當顯示名稱。 少寫一個欄位不會讓模組壞掉，這是刻意的設計。

縮圖

預設會找模組資料夾底下的 icon.png。想換檔名或放子資料夾：

{
  "icon": "art/my-thumbnail.png"
}

路徑是相對於模組資料夾，不是相對於 Mods/。

換行怎麼寫

JSON 的字串不能直接按 Enter 換行，要用 \n：

{
  "description": "第一行\n第二行\n\n空一行後的第三行"
}
Windows 路徑的反斜線要跳脫 JSON 裡 \ 是特殊字元。icon 路徑請用正斜線 art/icon.png，不要寫 art\icon.png。 真的要寫反斜線得打兩個 \，很容易出錯，不建議。

寫壞了會怎樣

如果 mod.json 存在但格式錯誤（少逗號、多逗號、引號沒關）， 模組還是會出現在列表裡，但會被標記為壞掉。

格式寫壞的模組不會消失，會列在那裡標成壞的。因為直接消失的話你只會覺得 「檔案放錯地方了嗎」然後找一小時。

常見的 JSON 錯誤：

{
  "name": "我的模組",
  "author": "某人",     <-- 最後一個欄位不能有逗號
}

{
  "name": "我的模組"
  "author": "某人"      <-- 中間的欄位漏了逗號
}

{
  'name': '我的模組'    <-- JSON 只能用雙引號，不能用單引號
}
用 VS Code 編輯可以避開九成問題 它會即時標紅格式錯誤。或者把檔案內容貼到任何線上 JSON 檢查工具驗一次。

資料夾名不要改

啟用狀態綁在資料夾名上，不是 name 欄位 遊戲用資料夾名記住玩家有沒有啟用這個模組。
改 mod.json 的 name：安全，只是顯示名稱變了。
改資料夾名：對遊戲來說變成另一個模組，啟用狀態歸零，玩家要重新打開。 發布之後就不要再改資料夾名。

疑難排解

模組沒反應時照這章查。九成問題是 JSON 格式或名字打錯。

先做這三件事

  1. 回標題畫面，再「開始新遊戲」或「讀取存檔」 —— 資料在這兩個時機才合併，這是最常見的原因
  2. 確認模組是啟用狀態 —— 標題畫面 → 模組，開關要是打開的
  3. 把 JSON 貼到線上檢查工具驗一次 —— 搜尋「JSON validator」，任何一個都行
大部分問題到這裡就解決了 還是不行的話往下看按症狀分類的檢查。

症狀：模組列表裡沒有我的模組

檢查說明
有 mod.json 嗎最常見原因。沒有這個檔，資料夾會被完全忽略
檔名對嗎必須正好是 mod.json，不是 Mod.json 或 mod.json.txt
放對地方了嗎Mods/你的模組/mod.json，不是 Mods/mod.json
層數對嗎只掃 Mods/ 的直接子資料夾。放到孫層不會被找到
有「模組」按鈕嗎手機版和 Demo / 試玩版沒有模組功能
小心 Windows 隱藏副檔名 記事本存檔時容易變成 mod.json.txt，而 Windows 預設不顯示 .txt —— 看起來叫 mod.json，實際不是。
在檔案總管開啟「檢視 → 副檔名」確認。

症狀：模組出現在列表但被標記為壞掉

代表 mod.json 存在但格式錯誤。

常見錯誤範例
最後一個欄位多了逗號"author": "某人", 後面就是 }
中間欄位漏了逗號兩行之間沒有 ,
用了單引號'name' 應該是 "name"
引號沒關"name": "我的模組
用了反斜線沒跳脫"icon": "art\icon.png" 應該用 /
檔案不是 UTF-8中文變亂碼時的原因。存檔時選 UTF-8

症狀：模組有啟用，但資料沒生效

檢查說明
Name 有打錯嗎最常見原因。打錯就變成「新增一筆」而不是「修改」。注意全形半形、空格、簡繁
欄位名大小寫對嗎SellPrice 不是 Sellprice。打錯會被安靜忽略
資料夾名對嗎Data/Item/ 不是 Data/Items/
JSON 放對層數了嗎必須是 Data/<表名>/檔案.json。直接放 Data/檔案.json 不會被載入
該加引號的加了嗎裝備能力值欄位是文字，要寫 "Atk": "20"
回標題重進了嗎改完要回標題「開始新遊戲」或「讀取存檔」才會套用
資料放在 Data/ 底下但沒有子資料夾 = 不會載入 舊版的模組格式是直接放 Data/*.json，現在已經不支援。 必須放進表名資料夾：Data/Item/我的道具.json。
舊格式的 .csv 檔也不再讀取。

症狀：名字或介紹是空白的

漏填 Name_I2 Name 只是內部識別碼，玩家看到的是 Name_I2。
不做多語言也一定要填 Name_I2，直接寫你的母語就好。

症狀：圖片沒出現

見 加入圖片 的檢查清單。最常見的是：

  • 資料夾寫成 Image/（漏了 s），正確是 Images/
  • 子資料夾名大小寫錯（Rolehead vs RoleHead）
  • 資料裡的 ImageName 多寫了 .png
  • 檔案其實是 JPG 改成 .png 的（要真的轉檔）

症狀：音樂沒聲音

見 加入音樂音效 的檢查清單。最常見的是：

  • 放了音檔但沒在 Data/BGM/ 註冊
  • 註冊的 Name 跟音檔檔名不一致
  • 開機後太快測試（音檔在背景載入，等幾秒再試）
  • 檔案格式不支援（只吃 OGG / MP3 / WAV）

看遊戲的錯誤訊息

遊戲會把模組載入的過程寫進記錄檔。裡面有明確的錯誤原因，比猜快得多。

記錄檔位置：

C:\Users\<你的使用者名>\AppData\LocalLow\<公司名>\<遊戲名>\Player.log
怎麼找 在檔案總管的位址欄貼上 %USERPROFILE%\AppData\LocalLow 按 Enter， 然後往下找遊戲的資料夾。

用記事本開啟，搜尋 [Mod 就能看到所有模組相關訊息。

訊息對照表

訊息片段意思怎麼修
mod.json 解析失敗 JSON 格式錯誤 用 JSON 檢查工具驗證 mod.json
略過「XXX」：mod.json 解析失敗 整個模組被跳過 同上。修好格式後重開
沒有….json（提到 Data 底下） JSON 直接放在 Data/，沒放進表名資料夾 移到 Data/<表名>/ 底下
.csv 已不再… 用了舊版格式 改寫成 JSON，放進表名資料夾
讀取失敗 檔案讀不到或格式壞 檢查該檔案的 JSON 格式與編碼（要 UTF-8）
部分資料套用失敗 欄位名或型別有問題 訊息後面會說是哪個欄位，照著改
不是合法的 PNG，略過 檔案不是真的 PNG 用繪圖軟體重新輸出成 PNG，不要只改副檔名
不支援的音檔格式，略過 音檔格式不對 轉成 OGG / MP3 / WAV
音檔解碼後是空的 音檔壞了或是 0 位元組 重新輸出音檔
已套用 N 個模組、共 M 個資料 這是成功訊息 數字對不對？少了就是有檔案被跳過，往上找警告
找「已套用 N 個模組」這行最快 它會告訴你實際載入了幾個模組、幾個資料檔。數字跟你預期的不符， 就往上翻看有什麼警告。

還是解決不了

回報問題時請附上：

  • 你的 mod.json 內容
  • 出問題的那個 JSON 檔內容
  • 模組的資料夾結構（截圖或文字都行）
  • Player.log 裡所有含 [Mod 的行
遊戲內建回報功能 遊戲中按 F10 可以開啟問題回報，會自動附上必要的資訊。

快速開始

目標：五分鐘內做出一個會動的模組，確認整條流程通了。

1. 找到模組資料夾

模組放在遊戲安裝目錄底下：

<遊戲安裝資料夾>/Pirate_Data/StreamingAssets/Mods/

最快的找法：進遊戲 → 標題畫面 → 模組管理 → 開啟資料夾。遊戲會直接幫你開，不用自己翻。

如果沒有 Mods 資料夾 自己建一個就行，名字要正好是 Mods。
如果標題畫面連「模組」按鈕都沒有，代表你的版本不支援模組 —— 手機版和 Demo / 試玩版都沒有這個功能。

2. 建立你的模組資料夾

在 Mods/ 底下建一個資料夾。名字自訂，建議用英文和數字，避免空格：

Mods/
└── MyFirstMod/
資料夾名稱是模組的身分證 遊戲用資料夾名記住「這個模組有沒有被啟用」。
改名字 = 變成另一個模組，啟用狀態會歸零，玩家要重新打開。發布後就不要再改。

3. 寫 mod.json

在你的模組資料夾裡建一個 mod.json。沒有這個檔，遊戲不會認為那是模組， 連列表都不會出現。

{
  "name": "我的第一個模組",
  "author": "你的名字",
  "version": "1.0",
  "description": "測試用。加了一個超強藥水。"
}

所有欄位都可以省略，缺了會用預設值。詳細說明見 mod.json 欄位。

4. 加一筆資料

資料放在 Data/<表名>/ 底下，一個 JSON 檔就是一筆資料。 這裡加一個道具：

MyFirstMod/
├── mod.json
└── Data/
    └── Item/
        └── SuperPotion.json

SuperPotion.json 的內容：

{
  "Name": "超強藥水",
  "Name_I2": "超強藥水",
  "Desc": "喝下去會變得很強",
  "Type": "道具",
  "AddHP": 999
}
資料夾名決定改哪張表 Data/Item/ 改的是道具表，Data/Role/ 改角色表。
寫 Item 或 TheItem 都會被接受（遊戲會自動補上 The）。
檔名不重要，遊戲看的是檔案裡面的 Name 欄位。

5. 啟用並測試

  1. 回到遊戲，標題畫面 → 模組管理
  2. 找到「我的第一個模組」，按啟用
  3. 回到標題畫面，再「開始新遊戲」或「讀取存檔」
  4. 進遊戲看道具清單，應該有「超強藥水」
改完要回標題重新進入遊戲 模組資料在「開始新遊戲」與「讀取存檔」這兩個時機合併。 改完檔案或切換啟用狀態後，回到標題畫面再進一次遊戲就會生效 —— 不需要關掉遊戲重開。
已經在進行中的遊戲不會即時變動，要回標題再進來。

成功了嗎？

看到新道具 → 整條流程通了 接下來看 修改遊戲資料，學怎麼改既有內容、有哪些欄位可以填。
沒看到 → 去疑難排解 疑難排解 有錯誤訊息對照表和檢查清單。 九成的問題是 JSON 格式打錯（少一個逗號、多一個逗號）。

完整的模組長什麼樣

一個用到全部功能的模組結構：

MyMod/
├── mod.json              名片檔（必要）
├── icon.png              列表縮圖（選配）
├── Data/                 資料表
│   ├── Item/
│   │   └── SuperPotion.json
│   ├── Role/
│   │   └── NewHero.json
│   └── Skill/
│       └── MegaSlash.json
├── Images/               圖片
│   ├── RoleHead/
│   │   └── NewHero.png
│   └── Role/
│       └── NewHero.png
└── Music/                音樂與音效
    ├── BGM/
    │   └── BGM_MyTheme.ogg
    └── Sfx/
        └── se_MyHit.ogg

各部分的詳細規則在後面的章節。

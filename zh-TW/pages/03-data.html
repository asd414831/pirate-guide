修改遊戲資料

模組最主要的功能。改既有的數值，或憑空加新內容。

基本規則

Mods/<你的模組>/Data/<表名>/<任意檔名>.json
  • 資料夾名決定改哪張表 —— Data/Item/ 改道具，Data/Role/ 改角色
  • 一個 JSON 檔就是一筆資料 —— 一個道具一個檔，不要把多筆塞進一個檔
  • 檔名不重要 —— 遊戲看的是檔案裡的 Name 欄位。檔名純粹給你自己好認
寫 Item 或 TheItem 都可以 遊戲內部的表名是 TheItem，資料夾寫 Item 時會自動補上 The。 兩種寫法都收，少一個踩雷點。

合併規則（最重要的一節）

遊戲已經有一整份資料。你的 JSON 是疊在上面，不是取代它。 比對的依據是 Name 欄位：

你的 Name結果
遊戲裡已經有同名的 就地修改。只改你寫到的欄位，其他欄位保持原值
遊戲裡沒有同名的 新增一筆，加在清單最後面
只寫你要改的欄位就好 想讓某個道具賣貴一點，整個檔案只要兩行：
{ "Name": "藥草", "SellPrice": 500 }
其他欄位（名稱、圖示、效果）完全不受影響。
沒有「刪除」功能 模組不能移除遊戲既有的內容。想讓某個東西不出現，用 UnlockCon 設一個永遠不成立的條件來隱藏它，而不是試圖刪除。

Name 是身分證

Name 打錯 = 變成新增 想改「藥草」但打成「藥革」，遊戲不會報錯 —— 它會認為你要新增一個叫「藥革」的道具。 結果：原本的藥草沒變，多了一個奇怪的新道具。
模組沒生效時，第一個要檢查的就是 Name 有沒有打錯（包含全形半形、空格）。

欄位名怎麼查

欄位名要跟遊戲內部一致，大小寫也要對。最可靠的查法是用演出編輯器的資料表功能 （見 演出編輯器），它會列出每張表的所有欄位。

欄位名打錯會被安靜忽略 把 SellPrice 打成 Sellprice（小寫 p），遊戲不會報錯， 那一行就是沒有效果。改完沒反應時要檢查大小寫。

型別：什麼時候加引號

JSON 的數字和文字寫法不同，要跟遊戲的欄位型別對上。

{
  "Name": "超強藥水",
  "SellPrice": 500,          數字，不加引號
  "AddHP": 999,              數字，不加引號
  "Name_I2": "超強藥水",     文字，要加引號
  "Atk": "20"                文字，要加引號（見下方說明）
}
裝備的能力值欄位是「文字」，不是數字 Atk / MaxHP / AtkPercent 這類欄位存的是算式字串， 所以要寫成 "Atk": "20" 而不是 "Atk": 20。
這樣設計是為了讓數值能隨等級變化。不確定某欄要不要加引號時， 去看遊戲本體同類型的資料怎麼寫的，照抄那個格式。

新增內容要填 ID

新增的資料 ID 必須大於 0，否則會被跳過 ID 是 0 或負數的資料被視為佔位列，不會出現在遊戲裡。
建議用 9000 以上的數字，避開遊戲本體未來新增的內容。
修改既有資料時不用填 ID（原本的會保留）。

清單型欄位

有些欄位可以放多個值，JSON 寫成陣列：

{
  "Name": "某個角色",
  "Skill": ["斬擊", "重斬", "迴旋斬"]
}
陣列是「整條取代」，不是「追加」 上面這樣寫，該角色的技能就只有這三個，原本的會被換掉。
想保留原有技能再加新的，你得把原有的也一起列出來。
為什麼不做成追加：同一個模組被套用兩次時，追加會變成 ["斬擊","重斬","斬擊","重斬"]。取代的行為才是可預期的。

逗號分隔的欄位

有些欄位遊戲內部存成「一串用逗號隔開的文字」（例如道具的 Tag）。 這種欄位兩種寫法都可以，效果一樣：

"Tag": "戰鬥中可用,水果"
"Tag": ["戰鬥中可用", "水果"]

範例：改既有道具

Data/Item/藥草改價.json

{
  "Name": "藥草",
  "SellPrice": 500
}

只有賣價變了，其他一切不動。

範例：新增道具

Data/Item/SuperPotion.json

{
  "Name": "超強藥水",
  "Name_I2": "超強藥水",
  "Desc": "喝下去會變得很強",
  "Type": "道具",
  "IconName": "Potion",
  "SellPrice": 1000,
  "AddHP": 999,
  "AddMP": 99
}
IconName 可以借用本體的圖 填遊戲既有的圖示名稱就會用那張圖。想用自己畫的圖見 加入圖片。

範例：讓敵人變強

Data/Enemy/史萊姆強化.json

{
  "Name": "史萊姆",
  "MaxHP": "200",
  "Atk": "30"
}

多語言

遊戲支援繁中 / 簡中 / 英文 / 日文 / 韓文 / 俄文。 名稱與說明欄位帶 _I2 的是給翻譯系統用的。

漏填 Name_I2 會讓名字整個空白 Name 只是內部用的識別碼，玩家看到的是 Name_I2。 只填 Name 沒填 Name_I2 的話，遊戲裡名字和介紹都會是空的， 而且不會有任何錯誤訊息。
不做多語言也一定要填 Name_I2，直接填你的母語文字就好。
文字結尾不要放標點符號 翻譯系統會把結尾的標點當成分隔符，導致翻譯查不到。
不要寫 "造成大量傷害。"，要寫 "造成大量傷害"。
句中的逗號也建議換成半形空格："場景過場中 無法存檔"。

套用順序

模組資料在遊戲開機時套用，順序是：

  1. 遊戲載入自己的資料
  2. 模組依序疊上去（多個模組時，後面的蓋前面的）

模組永遠疊在最上層，所以你的修改一定生效。多個模組互相衝突的情況見 多模組共存。

改完要回標題重新進入遊戲 資料在「開始新遊戲」與「讀取存檔」時合併。改完檔案後回標題再進一次就會生效， 不需要關掉遊戲重開。進行中的遊戲不會即時變動。

加入音樂音效

模組可以帶自己的 BGM 和音效。

基本規則

Mods/<你的模組>/Music/<任意子資料夾>/<音檔名>.ogg
項目說明
支援格式OGG / MP3 / WAV
推薦格式OGG —— 檔案小、載入快、無授權問題
子資料夾隨你怎麼分，不影響查找

命名是「純檔名」，不含路徑

這點跟圖片不同，最容易搞混 音樂的子資料夾純粹給你自己整理用，遊戲查找時只看檔名。
Music/BGM/MyTheme.ogg 和 Music/隨便/亂/MyTheme.ogg 對遊戲來說完全一樣，都是「MyTheme」。

所以下面這兩種放法效果相同：

Music/
├── BGM/
│   └── MyTheme.ogg          → 遊戲認得的名字是 "MyTheme"
└── Sfx/
    └── se_MyHit.ogg         → 遊戲認得的名字是 "se_MyHit"
Music/
├── MyTheme.ogg              → 一樣是 "MyTheme"
└── se_MyHit.ogg             → 一樣是 "se_MyHit"
不同資料夾撞名 = 其中一個消失 因為查找只看檔名，Music/BGM/Theme.ogg 和 Music/Sfx/Theme.ogg 會互相衝突，只有一個會生效。
建議自己加前綴避開：BGM_ / se_。

加一首 BGM

兩個步驟，缺一個都沒聲音。

1. 放音檔

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. 註冊到 BGM 清單

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "曲子的說明文字",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "作曲者"
}
只放音檔不註冊，或只註冊不放音檔，都是安靜失敗
  • 只放音檔 → 遊戲裡沒有任何地方會用到它
  • 只註冊 → 清單裡看得到名字，播放時沒有聲音
兩種情況都不會有錯誤訊息。
ID 必須大於 0，否則不會出現在清單 ID 是 0 或負數的資料會被當成佔位列跳過。
建議用 9000 以上的數字，避開遊戲本體未來新增的內容。
其他欄位
  • Name —— 要跟音檔檔名一致（不含 .ogg）
  • Desc —— 曲子的說明文字
  • Path —— 純顯示用，寫音檔檔名就好
  • Maker —— 作曲者
音樂清單預設是鎖著的 玩家第一次在遊戲裡實際播到這首時會自動解鎖，不用另外設定。

換掉本體的音樂

用跟本體一樣的檔名，就會蓋掉。不需要註冊（本體已經註冊過了）：

Music/BGM_Title.ogg      <-- 換掉標題畫面音樂
模組音檔優先於本體音檔 跟圖片一樣的規則。想做「全部換成自己的配樂」的模組完全可行。

音效

音效跟 BGM 走同一個資料夾，規則完全一樣。差別只在音效不需要註冊到清單 —— 它是由技能或演出指定名字來播放的。

Music/Sfx/se_MyHit.ogg

然後在技能或演出裡指定播放 se_MyHit。

載入時機（重要）

音檔在背景慢慢載入，開機後前幾秒可能還沒好 跟圖片不同，音檔（尤其 MP3）要花時間解碼。遊戲的做法是：
開機時先記住有哪些檔案（很快），然後在背景逐個解碼。
所以「遊戲剛開機的前幾秒」播放模組音樂，可能會沒聲音或播到本體的音樂。 等一下再播就正常了。
這不是 bug，也不需要處理 實際遊玩時玩家不會在開機瞬間就進到用模組音樂的場景。 但你自己測試時如果「第一次沒聲音、再試一次就有」，原因就是這個。

檔案大小建議

用途建議理由
BGMOGG，2～5 MB循環播放的曲子，用 OGG 壓縮效率最好
音效OGG 或 WAV，< 500 KB短音效用 WAV 也可以，解碼最快
避免大檔 WAV一首 WAV 的 BGM 可能 50 MB 以上，載入慢又佔空間

檢查清單

沒聲音的時候按順序檢查：

  1. 音檔放在 Music/ 底下嗎？
  2. 格式是 OGG / MP3 / WAV 嗎？（不是改副檔名，要真的轉檔）
  3. 要當 BGM 的話，Data/BGM/ 有註冊嗎？
  4. 註冊的 Name 跟音檔檔名完全一致嗎？（不含副檔名）
  5. 有跟其他音檔撞名嗎？
  6. 是不是開機後太快就測試了？（等幾秒再試）
  7. 回標題重新「開始新遊戲」或「讀取存檔」了嗎？

トラブル対処

MODが反応しないとき。9割はJSONの書式ミスか名前のタイプミスです。

まずこの3つ

  1. タイトル画面に戻り、「新規開始」か「セーブ読み込み」 — データはこの2つのタイミングでしかマージされません。最も多い原因
  2. MODが有効か確認 — タイトル画面 → MOD管理
  3. JSONをオンラインバリデータで確認

症状：MOD一覧に出てこない

確認説明
mod.json はありますか最も多い原因。無いとフォルダごと無視されます
ファイル名は正しいですか正確に mod.json
置き場所は正しいですかMods/あなたのMOD/mod.json
階層は正しいですか走査されるのは Mods/ の直下のみ
MOD管理ボタンはありますかスマホ版と体験版は非対応
Windowsの拡張子非表示に注意 メモ帳で保存すると mod.json.txt になりがちで、Windowsは .txt を隠します。
エクスプローラーの「表示 → ファイル名拡張子」で確認を。

症状：一覧に出るが「壊れている」

よくあるミス例
最後の項目に余分なカンマ"author": "誰か", の次が }
項目間のカンマ抜け2行の間に , が無い
シングルクォート'name' は "name"
引用符の閉じ忘れ"name": "私のMOD
バックスラッシュart\icon.png — / を使う
UTF-8でない日本語が文字化けする原因

症状：有効なのにデータが反映されない

確認説明
Name のタイプミス最も多い原因。ミスすると「変更」が「追加」に
項目名の大文字小文字SellPrice、Sellprice ではない
フォルダ名Data/Item/、Data/Items/ ではない
JSONの階層Data/ 直下は読み込まれません
引用符装備の能力値は文字列："Atk": "20"
ID は 0 より大きい0以下はスキップされます
Data/ 直下のJSONは読み込まれません 旧形式は非対応です。テーブルフォルダに入れてください。 旧形式の .csv も無視されます。

症状：名前や説明が空欄

Name_I2 が抜けています プレイヤーが見るのは Name_I2 です。 多言語対応しない場合でも記入してください。

症状：画像が出ない

  • フォルダ名が Image/（sが無い）
  • サブフォルダの大文字小文字が違う
  • ImageName に .png が入っている
  • 実体はJPGなのにリネームしただけ
  • 差分画像を顔サイズに切り抜いてしまった

症状：音が出ない

  • Data/BGM/ に登録していない
  • 登録した Name がファイル名と一致していない
  • ID が 0 以下
  • 起動直後すぎる（数秒待つ）
  • 非対応形式
項目名を間違えると正しい名前を教えてくれます 
[ModPatch] Item/ExamplePotion.json 1件目：
  TheItem に項目「IconImage」はありません。「IconName」ですか？
わざと近い名前を書いて候補を読むのが早道です。

ゲームのログを読む

C:\Users\<ユーザー名>\AppData\LocalLow\<会社名>\<ゲーム名>\Player.log
行き方 エクスプローラーのアドレス欄に %USERPROFILE%\AppData\LocalLow を貼ってEnter。

[Mod で検索すればMOD関連のメッセージが見られます。

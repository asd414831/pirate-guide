演出とコンテンツ付与

データを書いただけでは「存在する」だけ。プレイヤーはまだ持っていません。

ここが最も見落とされる工程です Data/Role/ にキャラを追加してデータが完璧でも、プレイヤーには永久に届きません。
アイテムには価格項目があるので勝手に店へ並びますが、 キャラとステージにはそれがありません。渡す手段は演出命令だけです。

演出とは

演出（Show）はゲーム命令の並びです。会話にもなれば、純粋なデータ操作にもなります。 Data/Show/ に1件1ファイルで置きます。

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddRole>NewHero"
  ]
}
演出の項目はちょうど4つ ID / Name / Tag / Shows。 説明項目はなく、書いても無視されます。

AutoRun：能動的に動ける唯一のフック

Tag に AutoRun を入れると、 新規開始後とセーブ読み込み後に自動再生されます。

Data/Show/AutoRun.json

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddRole>NewHero",
    "<AddItem>SuperPotion,1"
  ]
}
AutoRunは毎回走ります。1回だけではありません 新規開始のたび、セーブ読み込みのたびに実行されます。
通常は無害です — <AddRole> と <AddItem> は 既に持っている対象をスキップします。重複もせず、レベルも戻りません。

本当に1回だけにしたいならフラグで囲みます：

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<if>{MyModInit}==0",
    "<AddRole>NewHero",
    "<Var>MyModInit,=,1",
    "<endif>"
  ]
}
Name にはMOD名を Name はマージキーです。2つのMODのAutoRunが同名だと後のものが無言で上書きします。
Tag は「含む」判定 "Tag": "AutoRun,劇情" でも有効。大文字小文字も区別しません。

キャラクターの付与

<AddRole>NewHero

引数はキャラデータの Name（Name_I2 ではありません）。

船員一覧に出すにはあと2条件
  • ID が 0 より大きい
  • Name が空でない
満たさないと <AddRole> が走っても見えません。

ステージの付与

2行とも必要です。

<AddStageGroup>モジュール
<AddStage>深淵の試練
<AddStageGroup> が無いとステージは見えません ステージはグループにぶら下がる必要があります。 ゲームには「モジュール」という組み込みグループがあり、そのまま使えます。
繰り返し実行しても安全 既に持っているものは二重に追加されません。

アイテムの付与

<AddItem>SuperPotion,1
アイテムには通常AutoRun不要 SellPrice を設定すればショップに並びます。 <AddItem> は直接渡したいときだけ。

AutoRunの注意点

セーブがストーリー途中だと同時進行になります 読み込み時に会話が再開する場合、AutoRunが画面を取り合います。
純粋なデータ命令だけを置くことを推奨 — <AddRole>、<AddItem>、<AddStage>、 <Var>。
会話や間はステージの勝利演出のほうが自然です（次章）。
複数MODのAutoRunは直列実行 順番はMOD一覧の並び順（上から下）。 AutoRun内の <Wait> は意図どおり働き、他のMODは割り込みません。

命名規則：ゲームの演出枠を埋める

ゲームの各所は決まった名前で演出を探しています。 その名前にすれば呼ばれ、Tag は不要です。

ホーム画面のキャラ会話

ホーム画面で立ち絵をクリックしたとき再生：

主畫面角色對話_<キャラの Name>
Data/Show/RoomTalk.json

{
  "Name": "主畫面角色對話_NewHero",
  "Shows": [
    "<Var>主畫面對話值,+,1",
    "<if>{主畫面對話值}>3",
    "<Var>主畫面對話值,=,1",
    "<endif>",
    "<if>{主畫面對話值}==1",
    "<MateImage>NewHero",
    "<MateTalk>{目前主畫面角色名稱}：やあ。",
    "<elseif>{主畫面對話值}==2",
    "<MateTalk>{目前主畫面角色名稱}：また君か。",
    "<elseif>",
    "<MateTalk>{目前主畫面角色名稱}：用も無いのにつつくな。",
    "<endif>"
  ]
}
用意しなくてもエラーにはなりません MODキャラが黙って立っているだけになります。使うのはデータの Name で、 翻訳後の表示名ではありません。

命令早見表

命令効果
<AddRole>Nameキャラクターを渡す
<AddItem>Name,個数アイテムを渡す
<AddStageGroup>名前ステージグループを解放
<AddStage>Nameステージを解放
<Var>変数,=,値変数を設定（= / + / -）
<if>条件 … <endif>条件分岐。間に <elseif>
<Talk>本文会話。本文なしでウィンドウを閉じる
<MateTalk>本文ホーム画面の会話
<Wait>秒数待機
<BG>名前,秒数,色背景。<BG>,1 でフェードアウト
<Image>スロット,キャラ,表情,衣装立ち絵。引数なしで全消去
<MateImage>キャラ,表情,衣装ホーム画面の立ち絵
<BGM>名前BGM切り替え
<Sfx>名前効果音再生
全一覧は演出エディタに 命令は多く引数も細かいので、演出エディタなら 説明を見ながらメニューから選べます。

会話の書き方

話者は「名前：本文」：

<Talk>NewHero：おはよう。
キャラ名と一致すると自動で色とスポットライトが付きます 照合はデータの Name。一致しなければただの文字列で、エラーにはなりません。

ストーリー区間の開始と終了

<BG>MyBG,0,#00000000      背景を設定、完全透明
<BG>MyBG,1,#FFFFFF        1秒でフェードイン
<Talk>誰か：最初のセリフ。
<Talk>                     ウィンドウを閉じる
<Image>                    立ち絵を消す
<BG>,1                     背景をフェードアウト

チェックリスト

追加したのにプレイヤーに見えない：

  1. AutoRun演出を書きましたか？（最も多い原因）
  2. Tag に AutoRun が含まれていますか？
  3. <AddRole> の引数はデータの Name ですか？
  4. ID は 0 より大きいですか？
  5. ステージなら <AddStageGroup> を書きましたか？
  6. タイトルに戻って入り直しましたか？

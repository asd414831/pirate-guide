音楽と効果音の追加

MODは独自のBGMと効果音を同梱できます。

基本ルール

Mods/<あなたのMOD>/Music/<任意のサブフォルダ>/<名前>.ogg
項目内容
対応形式OGG / MP3 / WAV
推奨OGG — 容量が小さく、読み込みが速く、ライセンス問題もなし
サブフォルダ好きに整理してOK。検索には影響しません

名前は「ファイル名のみ」でパスを含みません

これは画像と逆なので混同しやすい点です 音声のサブフォルダは純粋に整理用で、検索はファイル名だけを見ます。
Music/BGM/MyTheme.ogg と Music/なんでも/入れ子/MyTheme.ogg は ゲームから見てまったく同じ、どちらも「MyTheme」です。

したがって次の2つは同じ挙動になります：

Music/
├── BGM/
│   └── MyTheme.ogg          → ゲームが認識する名前は "MyTheme"
└── Sfx/
    └── se_MyHit.ogg         → ゲームが認識する名前は "se_MyHit"
Music/
├── MyTheme.ogg              → やはり "MyTheme"
└── se_MyHit.ogg             → やはり "se_MyHit"
別フォルダの同名ファイルは片方が消えます 検索がファイル名だけを見るため、Music/BGM/Theme.ogg と Music/Sfx/Theme.ogg は衝突し、片方しか有効になりません。
自分で接頭辞（BGM_、se_）を付けて回避してください。

BGMを1曲追加する

2ステップ。どちらか欠けると音が出ません。

1. 音声ファイルを置く

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. BGMリストに登録する

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "曲の説明文",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "作曲者名"
}
ファイルだけ、あるいは登録だけ — どちらも無言で失敗します
  • ファイルのみ → ゲーム内のどこからも参照されない
  • 登録のみ → リストに名前は出るが音が鳴らない
どちらの場合もエラーメッセージは出ません。
ID が 0 より大きくないとリストに出ません ID が 0 以下のデータはプレースホルダ行とみなされます。
9000 以上を推奨します。
その他の項目
  • Name — 音声ファイル名と一致させる（.ogg は除く）
  • Desc — 説明文
  • Path — 表示専用。ファイル名でOK
  • Maker — 作曲者
音楽リストは最初ロックされています ゲーム内で実際にその曲が再生されると自動的に解放されます。追加設定は不要です。

ゲーム本体の音楽を差し替える

同じファイル名にするだけです。登録は不要 （ゲームが既に登録済みのため）：

Music/BGM_Title.ogg      <-- タイトル画面の曲を差し替え
MODの音声がゲーム本体より優先されます 画像と同じルールです。「サウンドトラック総入れ替え」MODも可能です。

効果音

効果音もBGMと同じフォルダ・同じルールです。違いは 登録が不要な点だけ — スキルや演出が名前で指定します。

Music/Sfx/se_MyHit.ogg

あとはスキルや演出で se_MyHit を指定します。

読み込みタイミング（重要）

音声はバックグラウンドで読み込まれ、起動直後の数秒は準備できていません 画像と違い、音声（特にMP3）はデコードに時間がかかります。ゲームの方式は：
起動時にファイル一覧だけ記録（高速）、その後 バックグラウンドで順次デコード。
そのため起動直後の数秒でMOD音声を再生すると、無音になるかゲーム本体の曲が鳴ります。 少し待てば正常になります。
バグではなく、対処も不要です 実際のプレイで起動1秒後にMOD音楽の場面へ到達することはありません。ただ、 自分でテストしていて「1回目は無音、2回目は鳴る」なら理由はこれです。
唯一の例外はタイトル画面のBGM差し替えで、その瞬間はまだ読み込み中の可能性があるため、 読み込み完了後にゲームが1回鳴らし直します。
MP3も使えますがOGGが安全です MP3デコーダの対応状況は環境によって差があります。失敗時はゲームが警告を出します （無言で失敗はしません）。OGGはUnityのネイティブ形式で最も確実です。

ファイルサイズの目安

用途推奨理由
BGMOGG、2–5 MBループする曲はOGGの圧縮効率が最良
効果音OGG か WAV、500 KB 未満短い効果音はWAVでも可。デコードが最速
避けるべき大きなWAVWAVのBGMは50 MB超になることも。読み込みが遅く容量も無駄

チェックリスト

音が出ないときは順番に：

  1. ファイルは Music/ の下にありますか？
  2. OGG / MP3 / WAV ですか？（リネームではなく実際に変換したもの）
  3. BGMの場合、Data/BGM/ に登録しましたか？
  4. 登録した Name はファイル名と完全一致していますか？（拡張子なし）
  5. ID は 0 より大きいですか？
  6. 他の音声ファイルと名前が衝突していませんか？
  7. 起動直後すぎませんか？（数秒待ってから）
  8. タイトルに戻って「新規開始」か「セーブ読み込み」をしましたか？

ステージと敵

戦闘を一式作る。敵、AI、ウェーブ、背景、演出。

敵

Data/Enemy/Emma.json

{
  "Name": "エマ",
  "ID": 9201,
  "PSB": "Emma,Normal,Normal",
  "WellTerrain": "洞窟",
  "StartHP": 420, "LvAddHP": 18,
  "StartAtk": 48, "LvAddAtk": 1,
  "Pos_y": -1120, "Sca": 48,
  "DoID":    ["1",        "1",           "1"],
  "DoCON":   ["",         "{Turn}%4==3", "{Turn}%3==0"],
  "DoSkill": ["連続拳", "高速治癒",    "防御"]
}

敵AI：3本の並行リスト

DoID / DoCON / DoSkill は 対応する3本のリスト。同じ位置が1つのルールです。

項目意味
DoID重み。大きいほど選ばれやすい。-1 は開幕パッシブ
DoCON発動条件。空文字列は常に成立
DoSkillスキル名。既存のもの、または自分で追加したものと一致させる
長さが揃わない場合は最短に合わせられます はみ出した分は無言で無視。自分で数えてください。

上の例：

  • 通常は「連続拳」
  • 3、7、11…ターン目は「高速治癒」
  • 3、6、9…ターン目は「防御」

立ち絵の位置とサイズ

項目説明
Pos_y戦闘画面での縦位置。雑魚はおおむね -1120 付近
Sca拡大率。雑魚はおおむね 70–80
体格の近い既存敵を真似るのが早道 同じくらいの大きさの敵の Pos_y / Sca をコピーして微調整。
調整にゲーム再起動は不要 保存してタイトルに戻り、入り直せば反映されます。

敵の立ち絵の置き場所

キャラクターと同じルール（画像の追加 参照）。 違いは項目名が PSB であることだけ。

Images/Role/Emma/Body/Body_Normal.png
Images/Role/Emma/Face/Face_Normal.png

PSB の3つは「PSB名,表情,衣装」：

"PSB": "Emma,Normal,Normal"
キャラと敵で立ち絵を共用できます サンプルのエマは敵として登場し、勝利後に同じ PSB で仲間になります。
Pos_y / Sca は各テーブルで別々に — 構図が違うためです。

ステージ

{
  "Name": "深淵の試練",
  "ID": 9201,
  "Group": "モジュール",
  "Tag": "戦闘",
  "Rank": 1,
  "FightWinExp": "60", "FightWinMoney": "60",
  "FightWhere": "洞窟",
  "FightBackground": "Background_ModAbyss, Background_ModAbyss_Night",
  "FightBGM": "BGM_Fight2",
  "EnemyLv": ["3", "5"],
  "Enemys":  ["エマ", "エマ, クラゲ"],
  "GetItem": ["リンゴ"],
  "GetItemProbability": ["0.5"]
}
項目説明
Groupステージ選択画面のグループ。「モジュール」が組み込みで使えます
Tag「戦闘」が無いと演出だけで戦闘は始まりません
FightWhere場所。地形相性に影響
FightBackground戦闘背景。カンマ区切りでウェーブごとに変更
FightBGM戦闘BGM。カンマ区切りでウェーブごとに変更

ウェーブ

Enemys の要素1つが1ウェーブ 同じウェーブに複数出すならカンマで区切ります。 
"Enemys": ["エマ", "エマ, クラゲ"]     1波目1体、2波目2体
"Enemys": ["エマ,クラゲ"]              1波で2体（空白は自由）
ゲーム既存の敵も使えます 「クラゲ」はゲーム本体の敵です。
同じウェーブに同名の敵を2体入れないでください ゲームの複数箇所が敵を名前で引いて位置を特定しています。 同名が2体いると常に1体目しか見つからず、2体目のエフェクト座標とターゲットが 1体目に飛びます。
同種を2体出すならデータを複製して別名にしてください （本体の「騎士 / 騎士B / 騎士C」がこの方式）。
ウェーブをまたいだ同名は問題ありません。

並行して対応するリスト

項目の組対応
Enemys / EnemyLv要素1つ = 1ウェーブ
FightBackground / FightBGMカンマ区切り、1つ = 1ウェーブ
GetItem / GetItemProbability同じ位置 = 同じドロップ
リストが短い場合は流用されます EnemyLv が足りなければ自動算出、 FightBackground / FightBGM は最初の1つが使われます。

ステージ演出

項目タイミング
StartShow進入時、戦闘開始前
FightWinShow勝利後
FightLoseShow敗北後

3つとも任意。演出本体は Data/Show/ に （演出とコンテンツ付与 参照）。

開始演出の例

{
  "Name": "深淵の試練_開始",
  "Tag": "劇情",
  "Shows": [
    "<BG>Background_ModAbyss,0,#00000000",
    "<BG>Background_ModAbyss,1,#FFFFFF",
    "<Talk>深淵の最奥から、場違いな聖歌が聞こえてきた。",
    "<Image>Mid,Emma,Normal",
    "<Talk>エマ：……♪",
    "<Image>Mid,Emma,Shock",
    "<ImageShake>Mid",
    "<Talk>エマ：あら、お客様。",
    "<Talk>",
    "<Image>",
    "<BG>,1"
  ]
}
慣例
  • 冒頭の2行の <BG> で背景フェードイン
  • 本文なしの <Talk> はウィンドウを閉じる
  • 引数なしの <Image> は立ち絵を全消去
  • 末尾の <BG>,1 で戦闘画面に引き継ぐ

「勝ってこそ仲間になる」

AutoRunより自然な付与方法 — AutoRunは「有効にした瞬間」、勝利演出なら「勝ち取る」形：

<Image>Mid,Emma,Laugh
<Talk>エマ：それじゃ、約束どおり今日から同行させてもらうわ。
<Talk>
<Image>
<AddRole>エマ
<BG>,1
周回してもフラグ管理は不要 <AddRole> は既に持っているキャラに対して安全です。

戦闘中のターン演出

ステージ項目に書く必要はなく、名前が合えば呼ばれます：

{ステージName}_Wave{波}_{PlayerTurn|EnemyTurn}{ターン}
演出 Nameタイミング
深淵の試練_Wave2_PlayerTurn12波目、プレイヤーの1ターン目
深淵の試練_Wave2_PlayerTurn2波目のすべてのプレイヤーターン
深淵の試練_PlayerTurn3戦闘全体の3ターン目
数字付きが優先されます 両方あれば1ターン目は数字付きが再生されます。

戦闘中の慣例は異なります

戦闘中は null と半透明の黒をマスクとして重ねます：

<BG>null,0,#00000000
<BG>null,0.5,#000000CC      戦闘画面を暗くする
<Wait>1
<Image>Mid,Emma,Shock
<Talk>エマ：ちょっと、本気なの？
<Talk>
<Image>
<BG>,0.5                    マスク解除、戦闘へ戻る
<EnemyImage>エマ,Emma,Sad   場上の表情を変更
<EnemyImage> はマスク解除の後に 暗転したままだとプレイヤーには見えません。

ステージをプレイヤーに見せる

データだけでは「存在する」だけ AutoRun演出で渡してください。2行とも必要： 
{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddStageGroup>モジュール",
    "<AddStage>深淵の試練"
  ]
}

スキル

Skill の最初の4つは基本スキル、条件は5つ目から 5つ目以降が順番に ElseSkillCon と対応： 
Skill[4] <- ElseSkillCon[0]
Skill[5] <- ElseSkillCon[1]
最初の4つ分の空文字列は不要です。

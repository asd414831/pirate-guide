Adding Audio

Mods can ship their own music and sound effects.

The basic rule

Mods/<your mod>/Music/<any subfolder>/<name>.ogg
ItemDetail
Supported formatsOGG / MP3 / WAV
RecommendedOGG — small, fast to load, no licensing issues
SubfoldersOrganise however you like; they don't affect lookup

The name is the bare filename, no path

This is the opposite of images, and it's easy to mix up Audio subfolders are purely for your own organisation; lookup only uses the filename.
Music/BGM/MyTheme.ogg and Music/whatever/nested/MyTheme.ogg are identical as far as the game is concerned — both are "MyTheme".

So these two layouts behave the same:

Music/
├── BGM/
│   └── MyTheme.ogg          → the game knows it as "MyTheme"
└── Sfx/
    └── se_MyHit.ogg         → the game knows it as "se_MyHit"
Music/
├── MyTheme.ogg              → still "MyTheme"
└── se_MyHit.ogg             → still "se_MyHit"
Same filename in different folders = one of them disappears Because lookup only uses the filename, Music/BGM/Theme.ogg and Music/Sfx/Theme.ogg collide and only one wins.
Prefix your own files (BGM_, se_) to avoid it.

Adding a BGM track

Two steps. Miss either one and there's no sound.

1. Drop in the audio file

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. Register it in the BGM list

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "Description of the track",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "Composer name"
}
File without registration, or registration without file — both fail silently
  • File only → nothing in the game ever references it
  • Registration only → the name appears in the list but plays nothing
Neither case produces an error message.
ID must be greater than 0 or it won't be listed Entries with ID 0 or negative are treated as placeholder rows.
Use 9000 or above to stay clear of content the game might add later.
The other fields
  • Name — must match the audio filename (without .ogg)
  • Desc — description text
  • Path — display only; the filename is fine
  • Maker — composer
Music gallery entries start locked They unlock automatically the first time the track actually plays in game. No extra setup.

Replacing the game's music

Use the same filename as the original. No registration needed — the game already registered it:

Music/BGM_Title.ogg      <-- replaces the title screen music
Mod audio takes priority over the game's Same rule as images. A "replace the whole soundtrack" mod is entirely possible.

Sound effects

Effects live in the same folder and follow the same rules. The only difference is that they don't need registering — skills and shows reference them by name.

Music/Sfx/se_MyHit.ogg

Then a skill or show plays se_MyHit.

Loading time (important)

Audio loads in the background; the first few seconds after startup it isn't ready Unlike images, audio (especially MP3) takes time to decode. What the game does is:
note which files exist at startup (fast), then decode them in the background.
So playing mod audio in the first few seconds after launch may produce silence or the game's original track. Try again a moment later and it's fine.
Not a bug, and nothing to work around In real play nobody reaches a mod-music scene in the first second. But if your own testing shows "no sound the first time, fine the second time", this is why.
The one exception is replacing the title screen BGM — that moment may still be loading, so the game replays it once loading finishes.
MP3 works but OGG is safer MP3 decoder support varies between environments. On failure the game logs a warning (it doesn't fail silently). OGG is Unity's native format and the most reliable.

Checklist

When there's no sound, in order:

  1. Is the file under Music/?
  2. Is it OGG / MP3 / WAV? (actually converted, not just renamed)
  3. For BGM, is it registered in Data/BGM/?
  4. Does the registered Name exactly match the filename (no extension)?
  5. Is ID greater than 0?
  6. Does the filename collide with another audio file?
  7. Did you test too soon after launch? (wait a few seconds)
  8. Did you return to the title screen and Start New Game or Load Game?
Licensing is your responsibility When releasing a mod, make sure you have the right to distribute the audio. Get permission for other people's work, or use material that is clearly free to use.

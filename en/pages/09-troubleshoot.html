Troubleshooting

When a mod does nothing. Nine times out of ten it's JSON syntax or a typo in a name.

Try these three first

  1. Return to the title screen, then Start New Game or Load Game — data is only merged at those two moments; this is the most common cause
  2. Check the mod is actually enabled — title screen → Mod Manager
  3. Paste the JSON into an online validator — search "JSON validator", any will do
Most problems end here If not, the checks below are organised by symptom.

Symptom: my mod isn't in the list

CheckNotes
Is there a mod.json?Most common cause. Without it the folder is ignored entirely
Is the filename right?Exactly mod.json — not Mod.json or mod.json.txt
Is it in the right place?Mods/YourMod/mod.json, not Mods/mod.json
Is the nesting right?Only direct subfolders of Mods/ are scanned
Is there a Mod Manager button at all?Mobile and demo builds don't support mods
Watch out for hidden file extensions on Windows Notepad easily saves mod.json.txt, and Windows hides the .txt by default — it looks like mod.json but isn't.
Turn on View → File name extensions in Explorer to check.

Symptom: it's listed but flagged as broken

That means mod.json exists but has a syntax error.

Common mistakeExample
Trailing comma on the last field"author": "Someone", followed by }
Missing comma between fieldsno , between two lines
Single quotes'name' should be "name"
Unclosed quote"name": "My Mod
Unescaped backslash"icon": "art\icon.png" — use /
File isn't UTF-8Why non-ASCII text turns to mojibake. Save as UTF-8

Symptom: enabled, but the data doesn't apply

CheckNotes
Typo in Name?Most common cause. A typo turns an edit into an addition. Watch for stray spaces and full-width characters
Field name case correct?SellPrice, not Sellprice
Folder name right?Data/Item/, not Data/Items/
JSON at the right depth?Must be Data/<table>/file.json. Files directly in Data/ aren't loaded
Quotes where needed?Equipment stat fields are text: "Atk": "20"
ID greater than 0?New entries with ID 0 or negative are skipped
Re-entered from the title screen?Check again
JSON directly under Data/ is never loaded The old mod format put files at Data/*.json. That's no longer supported. They must go in a table folder: Data/Item/MyItem.json.
Old-format .csv files are also ignored.

Symptom: the name or description is blank

Name_I2 is missing Name is only an internal identifier — players see Name_I2.
Fill it in even if you're not localising; just use your own language.

Symptom: images don't show

See the checklist in Adding Images. The usual suspects:

  • Folder spelled Image/ (missing the s) instead of Images/
  • Subfolder case wrong (Rolehead vs RoleHead)
  • ImageName includes .png
  • The file is actually a JPG renamed to .png
  • Variant images cropped to face size instead of full-body canvas

Symptom: no sound

See the checklist in Adding Audio. The usual suspects:

  • Audio file present but not registered in Data/BGM/
  • Registered Name doesn't match the filename
  • ID is 0 or negative
  • Tested too soon after launch (audio loads in the background — wait a few seconds)
  • Unsupported format (only OGG / MP3 / WAV)
When a field name is wrong, the game tells you the right one The actual message looks like this: 
[ModPatch] Item/ExamplePotion.json entry 1:
  TheItem has no field "IconImage", skipped. Did you mean "IconName"?
So when unsure of a field name, deliberately write something close and let the suggestion tell you the correct spelling. Faster than looking it up.

Reading the game's log

The game records the whole mod loading process. It states the actual cause, which beats guessing.

Log location:

C:\Users\<your username>\AppData\LocalLow\<company>\<game>\Player.log
How to get there Paste %USERPROFILE%\AppData\LocalLow into Explorer's address bar and press Enter, then find the game's folder.

Open it in a text editor and search for [Mod to see every mod-related message.

Message reference

Message fragmentMeaningFix
mod.json parse failed JSON syntax error Run mod.json through a JSON validator
skipping "XXX": mod.json parse failed The whole mod was skipped Same. Fix the syntax and re-enter the game
….json not in a table folder JSON sits directly in Data/ Move it into Data/<table>/
.csv no longer… Old format Rewrite as JSON in a table folder
read failed File unreadable or malformed Check that file's JSON syntax and encoding (must be UTF-8)
has no field "X"… Did you mean "Y"? Field name doesn't exist Use the suggested name
not a valid PNG, skipped The file isn't really a PNG Re-export as PNG; don't just rename
unsupported audio format, skipped Wrong audio format Convert to OGG / MP3 / WAV
decoded audio is empty Corrupt or zero-byte audio Re-export the audio
applied N mods, M data files This is the success message Do the numbers match? If not, scroll up for warnings
Find the "applied N mods" line first It tells you how many mods and data files actually loaded. If the count is lower than you expect, scroll up to find the warnings.

Still stuck

When reporting a problem, include:

  • Your mod.json
  • The JSON file that isn't working
  • Your mod's folder structure (screenshot or text)
  • Every line containing [Mod from Player.log
Built-in bug reporting Press F10 in game to open the report form; it attaches the necessary information automatically.

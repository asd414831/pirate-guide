Show Editor

Write shows visually — no typing commands, no memorising arguments.

What it is

The Show Editor is a web tool for editing the game's story scenes. It turns the commands from Shows & Granting Content into a clickable interface:

  • Pick commands from a list instead of remembering names and argument order
  • Browse backgrounds, portraits and expressions as thumbnails
  • Preview the dialogue box and portrait positions as you write
  • Export JSON your mod can use directly
Hand-writing vs the editor By hand you have to remember that <Image>'s first argument is the slot and the character comes second; you have to verify portrait filenames yourself; you have to count commas.
The editor turns all of that into menus and thumbnails. For anything longer than a dozen lines it's considerably faster.

What it does

FeatureNotes
Command menuEvery show command, categorised, with argument descriptions
Asset browserBackgrounds, portraits, expressions and stickers as thumbnails
Live previewSee the dialogue box, portrait placement and lighting as they'll appear
Mod assetsLoad your own mod's images alongside the game's
Data table fieldsLists every field of every table — very handy for looking names up
JSON exportOutput in the exact format Data/Show/ expects

You don't have to use it

Shows are plain JSON; a text editor works fine Shows & Granting Content and Stages & Enemies have complete examples to copy.
For a short show (an AutoRun with a single <AddRole>) a text editor is actually quicker.

How to get it

The editor isn't hosted on this site Check the game's official announcements or community channels.

Looking up field names without it

One of the editor's most useful features is browsing table fields. Without it:

  1. Read the official example mods — the examples under Mods/ already demonstrate most common fields
  2. Copy the game's own data — find a similar item in game and follow its format
  3. Let the game tell you — on a wrong field name it prints has no field "XXX", did you mean "YYY"?, which gives you the correct spelling
Point 3 is genuinely useful Write a field name that's deliberately close and read the suggestion. Faster than searching documentation.

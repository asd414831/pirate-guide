Quick Start

Goal: a working mod in five minutes, so you know the whole pipeline runs.

1. Find the mods folder

Mods live under the game's install directory:

<game install folder>/Pirate_Data/StreamingAssets/Mods/

Fastest way to get there: launch the game → title screen → Mod Manager → Open Folder. The game opens it for you.

If there's no Mods folder Just create one — it must be named exactly Mods.
If the title screen has no Mod Manager button at all, your build doesn't support mods — mobile and demo builds don't have the feature.

2. Create your mod folder

Make a folder inside Mods/. Name it whatever you like; English letters and digits are safest, avoid spaces:

Mods/
└── MyFirstMod/
The folder name is the mod's identity The game remembers "is this mod enabled" by folder name.
Renaming it makes it a different mod — the enabled state resets and players have to turn it back on. Don't rename after release.

3. Write mod.json

Create mod.json inside your mod folder. Without this file the game doesn't consider it a mod — it won't even show up in the list.

{
  "name": "My First Mod",
  "author": "Your Name",
  "version": "1.0",
  "description": "Testing. Adds an absurdly strong potion."
}

Every field is optional and falls back to a default. Details in mod.json Fields.

4. Add one piece of data

Data goes under Data/<table>/, and one JSON file is one entry. Here's an item:

MyFirstMod/
├── mod.json
└── Data/
    └── Item/
        └── SuperPotion.json

Contents of SuperPotion.json:

{
  "Name": "SuperPotion",
  "Name_I2": "Super Potion",
  "Desc": "Drink it and you get very strong",
  "Type": "Item",
  "AddHP": 999
}
The folder name decides which table you're editing Data/Item/ edits items, Data/Role/ edits characters.
Both Item and TheItem are accepted (the game prepends The for you).
The filename doesn't matter — the game reads the Name field inside the file.

5. Enable it and test

  1. Back in the game, title screen → Mod Manager
  2. Find "My First Mod" and press Enable
  3. Return to the title screen, then Start New Game or Load Game
  4. Check the shop — "Super Potion" should be there
Changes apply when you re-enter the game from the title screen Mod data is merged at two moments: Start New Game and Load Game. After editing files or toggling a mod, go back to the title screen and enter again — you do not need to restart the game.
A session already in progress won't change; you have to go back to the title.

Did it work?

See the new item → the whole pipeline works Next, read Editing Game Data to learn how to modify existing content and what fields are available.
Don't see it → go to troubleshooting Troubleshooting has an error message table and checks by symptom. Nine times out of ten it's a JSON syntax error (a missing comma, or one too many).

What a complete mod looks like

A mod using every feature:

MyMod/
├── mod.json              ID card (required)
├── icon.png              list thumbnail (optional)
├── Data/                 data tables
│   ├── Item/
│   │   └── SuperPotion.json
│   ├── Role/
│   │   └── NewHero.json
│   └── Skill/
│       └── MegaSlash.json
├── Images/               artwork
│   ├── RoleHead/
│   │   └── NewHero.png
│   └── Role/
│       └── NewHero.png
└── Music/                audio
    ├── BGM/
    │   └── BGM_MyTheme.ogg
    └── Sfx/
        └── se_MyHit.ogg

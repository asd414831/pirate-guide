Pirate Mod Making Guide

No programming needed. If you can use a text editor, you can make mods.

This guide covers making mods for Pirate — adding items, changing character stats, swapping artwork, adding your own music. Everything is done by editing text files. No development tools, no recompiling the game.

Your first mod takes five minutes Make a folder, write one mod.json, drop in one JSON file. That's it. Jump straight to Quick Start.

What you can do

  • Change values — characters, enemies, skills, buffs, items, stages, terrain… all 13 of the game's data tables are editable
  • Add new content — not just edit what exists; you can add entirely new items, characters and skills
  • Ship your own artwork — drop PNGs in Images/ and they load; add new portraits or replace the game's own
  • Ship your own audio — OGG / MP3 / WAV in Music/, both BGM and sound effects
  • Build whole battles — custom enemies, enemy AI, multi-wave stages, battle backgrounds
  • Write story scenes — dialogue, portraits, expression variants, stage intros and endings

What you can't do

  • Delete existing content — mods can only change and add. To hide something, use UnlockCon (see Editing Game Data)
  • Add new program logic — no C#. But the script commands and show system are already fairly flexible
  • Use mods on mobile — desktop only

Решение проблем

Когда мод ничего не делает. В девяти случаях из десяти виноват синтаксис JSON или опечатка в имени.

Сначала попробуйте эти три вещи

  1. Вернитесь на главный экран, затем «Новая игра» или «Загрузить игру» — данные объединяются только в эти два момента; это самая частая причина
  2. Проверьте, что мод действительно включён — главный экран → Менеджер модов
  3. Вставьте JSON в онлайн-валидатор — найдите «JSON validator», подойдёт любой
На этом большинство проблем заканчивается Если нет, проверки ниже сгруппированы по симптомам.

Симптом: мода нет в списке

ПроверкаПримечания
Есть ли mod.json?Самая частая причина. Без него папка игнорируется полностью
Верное ли имя файла?Ровно mod.json — не Mod.json и не mod.json.txt
Лежит ли он в нужном месте?Mods/YourMod/mod.json, а не Mods/mod.json
Верная ли вложенность?Просматриваются только прямые вложенные папки Mods/
Есть ли вообще кнопка «Менеджер модов»?Мобильная и демо-версии моды не поддерживают
Осторожно со скрытыми расширениями файлов в Windows «Блокнот» легко сохраняет mod.json.txt, а Windows по умолчанию скрывает .txt — выглядит как mod.json, но это не он.
Чтобы проверить, включите в Проводнике Вид → Расширения имён файлов.

Симптом: мод в списке, но помечен как повреждённый

Значит, mod.json есть, но в нём синтаксическая ошибка.

Частая ошибкаПример
Лишняя запятая в последнем поле"author": "Кто-то", и следом }
Нет запятой между полямимежду двумя строками отсутствует ,
Одинарные кавычки'name' должно быть "name"
Незакрытая кавычка"name": "My Mod
Неэкранированный обратный слэш"icon": "art\icon.png" — используйте /
Файл не в UTF-8Из-за этого не-ASCII текст превращается в кракозябры. Сохраняйте в UTF-8

Симптом: мод включён, но данные не применяются

ПроверкаПримечания
Опечатка в Name?Самая частая причина. Опечатка превращает правку в добавление. Следите за лишними пробелами и полноширинными символами
Верный ли регистр имени поля?SellPrice, а не Sellprice
Верное ли имя папки?Data/Item/, а не Data/Items/
JSON на нужной глубине?Должно быть Data/<таблица>/файл.json. Файлы прямо в Data/ не загружаются
Кавычки там, где нужно?Поля характеристик снаряжения — текст: "Atk": "20"
ID больше 0?Новые записи с ID 0 или отрицательным пропускаются
Вы заново вошли с главного экрана?Проверьте ещё раз
JSON прямо внутри Data/ не загружается никогда В старом формате модов файлы лежали в Data/*.json. Это больше не поддерживается. Они должны быть в папке таблицы: Data/Item/MyItem.json.
Файлы .csv старого формата тоже игнорируются.

Симптом: название или описание пустые

Не указано Name_I2 Name — это только внутренний идентификатор, а игроки видят Name_I2.
Заполняйте его, даже если не делаете локализацию: просто напишите на своём языке.

Симптом: изображения не показываются

См. контрольный список в главе Добавление изображений. Обычные подозреваемые:

  • Папка названа Image/ (без s) вместо Images/
  • Неверный регистр вложенной папки (Rolehead вместо RoleHead)
  • В ImageName указано .png
  • Файл на самом деле JPG, переименованный в .png
  • Изображения вариантов обрезаны до размера лица вместо холста во весь рост

Симптом: нет звука

См. контрольный список в главе Добавление аудио. Обычные подозреваемые:

  • Аудиофайл есть, но не зарегистрирован в Data/BGM/
  • Зарегистрированное Name не совпадает с именем файла
  • ID равен 0 или отрицателен
  • Проверяли слишком рано после запуска (аудио грузится в фоне — подождите несколько секунд)
  • Неподдерживаемый формат (только OGG / MP3 / WAV)
Если имя поля неверное, игра подскажет правильное Настоящее сообщение выглядит так: 
[ModPatch] Item/ExamplePotion.json entry 1:
  TheItem has no field "IconImage", skipped. Did you mean "IconName"?
Поэтому, если не уверены в имени поля, намеренно напишите что-то похожее и позвольте подсказке сообщить правильное написание. Быстрее, чем искать.

Как читать журнал игры

Игра записывает весь процесс загрузки модов. Там указана настоящая причина, а это лучше догадок.

Расположение журнала:

C:\Users\<ваше имя пользователя>\AppData\LocalLow\<компания>\<игра>\Player.log
Как туда попасть Вставьте %USERPROFILE%\AppData\LocalLow в адресную строку Проводника и нажмите Enter, затем найдите папку игры.

Откройте файл в текстовом редакторе и найдите [Mod, чтобы увидеть все сообщения, связанные с модами.

Справочник сообщений

Фрагмент сообщенияЧто значитЧто делать
mod.json parse failed Синтаксическая ошибка JSON Прогоните mod.json через валидатор JSON
skipping "XXX": mod.json parse failed Весь мод пропущен То же самое. Исправьте синтаксис и войдите в игру заново
….json not in a table folder JSON лежит прямо в Data/ Переместите его в Data/<таблица>/
.csv no longer… Старый формат Перепишите в JSON внутри папки таблицы
read failed Файл не читается или повреждён Проверьте синтаксис JSON и кодировку этого файла (нужен UTF-8)
has no field "X"… Did you mean "Y"? Такого имени поля не существует Используйте предложенное имя
not a valid PNG, skipped Файл на самом деле не PNG Переэкспортируйте в PNG, а не просто переименуйте
unsupported audio format, skipped Неверный формат аудио Сконвертируйте в OGG / MP3 / WAV
decoded audio is empty Повреждённый или пустой аудиофайл Переэкспортируйте аудио
applied N mods, M data files Это сообщение об успехе Совпадают ли числа? Если нет, прокрутите выше к предупреждениям
Сначала найдите строку «applied N mods» Она говорит, сколько модов и файлов данных на самом деле загрузилось. Если число меньше ожидаемого, прокрутите выше и найдите предупреждения.

Если всё ещё не выходит

Сообщая о проблеме, приложите:

  • Ваш mod.json
  • Файл JSON, который не работает
  • Структуру папок вашего мода (скриншот или текст)
  • Все строки с [Mod из Player.log
Встроенная отправка отчётов об ошибках Нажмите в игре F10, чтобы открыть форму отчёта: нужная информация прикрепится автоматически.

Этапы и враги

Как собрать полноценный бой. Враги, ИИ, волны, фоны, заставки.

Враги

Data/Enemy/Emma.json

{
  "Name": "Emma",
  "ID": 9201,
  "PSB": "Emma,Normal,Normal",
  "WellTerrain": "Cave",
  "StartHP": 420, "LvAddHP": 18,
  "StartAtk": 48, "LvAddAtk": 1,
  "Pos_y": -1120, "Sca": 48,
  "DoID":    ["1",          "1",           "1"],
  "DoCON":   ["",           "{Turn}%4==3", "{Turn}%3==0"],
  "DoSkill": ["Combo Punch", "Rapid Heal", "Defend"]
}

ИИ противника: три параллельных списка

DoID / DoCON / DoSkill — это три выровненных списка. Один и тот же индекс во всех трёх — это одно правило.

ПолеЗначение
DoIDВес. Чем больше, тем чаще выбирается. -1 означает пассивку на старте боя (навык в этом слоте DoSkill должен быть пассивным)
DoCONУсловие срабатывания. Пустая строка — всегда истинно
DoSkillИмя навыка. Должно совпадать с навыком игры или с добавленным вами в Data/Skill/
Списки разной длины обрезаются по самому короткому Лишнее молча игнорируется, без ошибок. Считайте сами.

Пример выше читается так:

  • Обычно применяет «Combo Punch»
  • На ходах 3, 7, 11… применяет «Rapid Heal» ({Turn}%4==3)
  • На ходах 3, 6, 9… применяет «Defend» ({Turn}%3==0)

Положение и масштаб портрета

ПолеПримечания
Pos_yПоложение по вертикали на боевом экране. У обычных врагов около -1120
ScaМасштаб. У обычных врагов около 70–80
Самый быстрый подход: скопируйте существующего врага похожего сложения Найдите в игре врага примерно нужного размера, скопируйте его Pos_y / Sca, а затем подстройте.
Для настройки портретов перезапуск игры не нужен Сохраните файл, вернитесь на главный экран, начните новую игру или загрузите сохранение — и всё применится.

Куда кладутся портреты врагов

Правила точно те же, что и для персонажей (см. Добавление изображений); разница лишь в том, что поле называется PSB.

Images/Role/Emma/Body/Body_Normal.png
Images/Role/Emma/Face/Face_Normal.png
Images/Role/Emma/Face/Face_Sad.png
Images/Role/Emma/Face/Face_Shock.png

Три части PSB — это «имя PSB, лицо, тело»:

"PSB": "Emma,Normal,Normal"
Персонажи и враги могут использовать один набор портретов Эмма из примера сначала появляется как враг, а после победы вступает в отряд, используя тот же PSB.
У каждой таблицы свои Pos_y / Sca — боевой экран и главный экран кадрируют её по-разному.

Этапы

Data/Stage/AbyssTrial.json

{
  "Name": "Abyss Trial",
  "ID": 9201,
  "Group": "Mods",
  "Tag": "Battle",
  "Rank": 1,
  "FightWinExp": "60", "FightWinMoney": "60",
  "FightWhere": "Cave",
  "FightBackground": "Background_ModAbyss, Background_ModAbyss_Night",
  "FightBGM": "BGM_Fight2",
  "EnemyLv": ["3", "5"],
  "Enemys":  ["Emma", "Emma, Jellyfish"],
  "GetItem": ["Apple"],
  "GetItemProbability": ["0.5"]
}
ПолеПримечания
GroupГруппа в меню этапов. В игре есть встроенная группа Mods
TagБез «Battle» этап только проигрывает постановку и боя не начинает
FightWhereМесто действия; влияет на соответствие типов местности
FightBackgroundБоевой фон. Через запятую — по одному на волну
FightBGMБоевая музыка. Через запятую — по одной на волну

Волны

Один элемент Enemys — это одна волна Несколько врагов в одной волне перечисляются в одной строке через запятую. 
"Enemys": ["Emma", "Emma, Jellyfish"]     волна 1: один враг, волна 2: два
"Enemys": ["Emma,Jellyfish"]              одна волна из двух (пробелы необязательны)
Можно использовать врагов самой игры «Jellyfish» выше — враг из базовой игры: добавлять своего не обязательно.
Никогда не ставьте двух врагов с одинаковым именем в одну волну Не пишите "Emma, Emma".
Несколько частей игры ищут врагов по имени, чтобы определить их место на поле. При двух одинаковых именах находится только первый — координаты эффектов и выбор цели второго попадут в первого.
Чтобы выставить двух одинаковых, сделайте копию данных под другим именем (собственные «Knight / Knight B / Knight C» игры сделаны именно так).
Одинаковое имя в разных волнах — нормально (каждая волна очищается и появляется заново).

Параллельные списки

Пара полейВыравнивание
Enemys / EnemyLvодин элемент = одна волна
FightBackground / FightBGMчерез запятую, по одному на волну
GetItem / GetItemProbabilityодин индекс = одна и та же добыча
Короткие списки используются повторно Если EnemyLv закончился, игра вычисляет уровни сама; FightBackground / FightBGM возвращаются к первому элементу.

Заставки этапа

Три поля принимают имена постановок:

ПолеКогда
StartShowПри входе, до боя
FightWinShowПосле победы
FightLoseShowПосле поражения

Все три необязательны. Сами постановки лежат в Data/Show/ (см. Постановки и выдача контента).

Пример вступительной постановки

Data/Show/StageStart.json

{
  "Name": "Abyss Trial_Start",
  "Tag": "Story",
  "Shows": [
    "<BG>Background_ModAbyss,0,#00000000",
    "<BG>Background_ModAbyss,1,#FFFFFF",
    "<Talk>Из глубин бездны донёсся неуместный гимн.",
    "<Image>Mid,Emma,Normal",
    "<Talk>Emma: ……♪",
    "<Image>Mid,Emma,Shock",
    "<ImageShake>Mid",
    "<Talk>Emma: О. Гости.",
    "<Talk>",
    "<Image>",
    "<BG>,1"
  ]
}
Соглашения
  • Вступительные <BG>имя,0,#00000000 + <BG>имя,1,#FFFFFF плавно проявляют фон
  • <Talk> без текста закрывает окно диалога
  • <Image> без аргументов очищает все три слота портретов
  • Завершающий <BG>,1 убирает фон, чтобы его сменил боевой экран

«Вступает в отряд только после победы»

Более естественный способ выдать персонажа, чем AutoRun: AutoRun отдаёт его сразу при включении мода, а постановка победы заставляет игрока его заслужить:

<Image>Mid,Emma,Laugh
<Talk>Emma: Что ж. Как договаривались — с сегодняшнего дня я с вами.
<Talk>
<Image>
<AddRole>Emma
<BG>,1
Для повторных прохождений флаг не нужен <AddRole> безопасен для персонажа, который у игрока уже есть — команда просто пропускается, без дубликатов и сброса уровня.

Постановки по ходам внутри боя

Постановки могут запускаться и в начале любого хода во время боя. На них не нужно ссылаться из данных этапа — достаточно совпадения имени:

{ИмяЭтапа}_Wave{n}_{PlayerTurn|EnemyTurn}{ход}

Волны и ходы считаются с 1. Например:

Имя постановкиКогда
Abyss Trial_Wave2_PlayerTurn1Волна 2, первый ход игрока
Abyss Trial_Wave2_PlayerTurnКаждый ход игрока в волне 2
Abyss Trial_PlayerTurn3Ход 3 всего боя (в любой волне)
Вариант с номером побеждает вариант без номера Если есть и _PlayerTurn1, и _PlayerTurn, на первом ходу проиграется вариант с номером.

Внутри боя соглашения другие

В сюжетных фрагментах используется фоновое изображение, а внутри боя — null плюс полупрозрачная чёрная накладка поверх боевого экрана:

<BG>null,0,#00000000
<BG>null,0.5,#000000CC      затемнить боевой экран
<Wait>1
<Image>Mid,Emma,Shock
<Talk>Emma: Погодите — вы серьёзно?
<Talk>
<Image>
<BG>,0.5                    убрать накладку, вернуться к бою
<EnemyImage>Emma,Emma,Sad   сменить её выражение на поле
<EnemyImage> должен идти после снятия накладки Смените выражение, пока экран ещё затемнён, — и игрок этого не увидит.

Как сделать этап видимым для игрока

Одни данные означают лишь, что этап существует — у игрока его нет Выдайте его постановкой AutoRun. Нужны обе строки: 
Data/Show/AutoRun.json

{
  "Name": "MyMod",
  "Tag": "AutoRun",
  "Shows": [
    "<AddStageGroup>Mods",
    "<AddStage>Abyss Trial"
  ]
}

См. Постановки и выдача контента.

Навыки

Навыки лежат в Data/Skill/. У полей навыков персонажа есть одно правило соответствия, в котором легко ошибиться:

Первые 4 элемента Skill — базовые навыки; условия начинаются с 5-го Первые четыре доступны с самого начала и условий не требуют.
С пятого они соответствуют по порядку полю ElseSkillCon: 
Skill[4] <- ElseSkillCon[0]
Skill[5] <- ElseSkillCon[1]
…
То есть ElseSkillCon не нужны пустые заглушки для первых четырёх.

Официальные моды-примеры

Вместе с игрой поставляется полный пример В папке Mods/ есть официальный пример, охватывающий целый этап: свой враг с вариантами выражений, этап из двух волн со сменой фона на каждой волне, заставки вступления / победы / поражения и персонаж, вступающий в отряд после победы.
Если не уверены, как записать поле, посмотрите туда.

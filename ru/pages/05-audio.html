Добавление аудио

Моды могут поставлять свою музыку и звуковые эффекты.

Базовое правило

Mods/<ваш мод>/Music/<любая вложенная папка>/<имя>.ogg
ПунктПодробности
Поддерживаемые форматыOGG / MP3 / WAV
РекомендуетсяOGG — компактный, быстро загружается, без лицензионных сложностей
Вложенные папкиРаскладывайте как удобно; на поиск они не влияют

Имя — это чистое имя файла, без пути

Здесь всё наоборот по сравнению с изображениями, и это легко перепутать Вложенные папки аудио нужны только вам для порядка; при поиске используется лишь имя файла.
Music/BGM/MyTheme.ogg и Music/whatever/nested/MyTheme.ogg для игры одно и то же — в обоих случаях это «MyTheme».

Поэтому эти две раскладки работают одинаково:

Music/
├── BGM/
│   └── MyTheme.ogg          → игра знает его как «MyTheme»
└── Sfx/
    └── se_MyHit.ogg         → игра знает его как «se_MyHit»
Music/
├── MyTheme.ogg              → по-прежнему «MyTheme»
└── se_MyHit.ogg             → по-прежнему «se_MyHit»
Одинаковое имя файла в разных папках = один из них пропадёт Так как при поиске учитывается только имя файла, Music/BGM/Theme.ogg и Music/Sfx/Theme.ogg конфликтуют, и побеждает только один.
Добавляйте свой префикс (BGM_, se_), чтобы этого избежать.

Добавление музыкального трека

Два шага. Пропустите любой — звука не будет.

1. Положите аудиофайл

MyMod/
└── Music/
    └── BGM/
        └── BGM_MyTheme.ogg

2. Зарегистрируйте его в списке BGM

Data/BGM/MyTheme.json

{
  "Name": "BGM_MyTheme",
  "ID": 9201,
  "Desc": "Описание трека",
  "Path": "BGM_MyTheme.ogg",
  "Maker": "Имя композитора"
}
Файл без регистрации или регистрация без файла — оба случая молча не работают
  • Только файл → в игре на него никто не ссылается
  • Только регистрация → название появится в списке, но ничего не заиграет
Ни в одном из случаев сообщения об ошибке не будет.
ID должен быть больше 0, иначе запись не попадёт в список Записи с ID 0 или отрицательным считаются строками-заготовками.
Берите 9000 и выше, чтобы не столкнуться с содержимым, которое игра может добавить позже.
Остальные поля
  • Name — должно совпадать с именем аудиофайла (без .ogg)
  • Desc — текст описания
  • Path — только для отображения; достаточно имени файла
  • Maker — композитор
Записи в галерее музыки изначально заблокированы Они открываются сами, когда трек впервые действительно звучит в игре. Дополнительно ничего настраивать не нужно.

Замена игровой музыки

Используйте то же имя файла, что у оригинала. Регистрация не нужна — игра уже зарегистрировала этот трек:

Music/BGM_Title.ogg      <-- заменяет музыку главного экрана
Аудио мода имеет приоритет над игровым Правило то же, что и для изображений. Мод «заменить весь саундтрек» вполне возможен.

Звуковые эффекты

Эффекты лежат в той же папке и подчиняются тем же правилам. Разница лишь в том, что их не нужно регистрировать — навыки и постановки ссылаются на них по имени.

Music/Sfx/se_MyHit.ogg

Дальше навык или постановка воспроизводит se_MyHit.

Время загрузки (важно)

Аудио грузится в фоне; первые несколько секунд после запуска оно не готово В отличие от изображений, аудио (особенно MP3) требует времени на декодирование. Игра делает так:
при запуске отмечает, какие файлы есть (быстро), а затем декодирует их в фоне.
Поэтому воспроизведение аудио мода в первые секунды после запуска может дать тишину или исходный трек игры. Повторите чуть позже — всё будет нормально.
Это не ошибка, и обходить это не нужно В реальной игре никто не добирается до сцены с музыкой мода за первую секунду. Но если при собственной проверке «в первый раз звука нет, во второй есть» — причина именно в этом.
Единственное исключение — замена BGM главного экрана: в этот момент загрузка может ещё идти, поэтому игра проигрывает трек заново, когда загрузка завершится.
MP3 работает, но OGG надёжнее Поддержка декодера MP3 отличается в разных окружениях. При сбое игра пишет предупреждение (то есть не молчит). OGG — родной формат Unity и самый надёжный.

Рекомендации по размеру файлов

НазначениеРекомендацияПочему
Фоновая музыкаOGG, 2–5 МБЗацикленные треки лучше всего сжимаются в OGG
Звуковые эффектыOGG или WAV, < 500 КБКороткие эффекты можно держать в WAV: он декодируется быстрее всего
Чего избегатьБольших WAVФоновый трек в WAV может весить 50 МБ и больше: медленно грузится и расточительно

Контрольный список

Если звука нет, по порядку:

  1. Файл лежит внутри Music/?
  2. Это OGG / MP3 / WAV? (реально сконвертированный, а не просто переименованный)
  3. Для музыки: зарегистрирован ли трек в Data/BGM/?
  4. Зарегистрированное Name точно совпадает с именем файла (без расширения)?
  5. ID больше 0?
  6. Имя файла не конфликтует с другим аудиофайлом?
  7. Не проверяли ли вы слишком рано после запуска? (подождите несколько секунд)
  8. Вы вернулись на главный экран и начали новую игру или загрузили сохранение?
Лицензии — ваша ответственность Выпуская мод, убедитесь, что имеете право распространять это аудио. Получите разрешение на чужие работы или используйте материалы, свободные для использования.

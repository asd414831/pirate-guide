Быстрый старт

Цель: рабочий мод за пять минут, чтобы убедиться, что вся цепочка работает.

1. Найдите папку модов

Моды лежат внутри папки установки игры:

<папка установки игры>/Pirate_Data/StreamingAssets/Mods/

Быстрее всего попасть туда так: запустите игру → главный экран → Менеджер модов → Открыть папку. Игра откроет её за вас.

Если папки Mods нет Просто создайте её — имя должно быть точно Mods.
Если на главном экране вообще нет кнопки «Менеджер модов», ваша сборка моды не поддерживает — в мобильной и демо-версиях этой функции нет.

2. Создайте папку своего мода

Создайте папку внутри Mods/. Название любое; надёжнее всего латинские буквы и цифры, пробелов лучше избегать:

Mods/
└── MyFirstMod/
Имя папки — это удостоверение мода Игра запоминает «включён ли этот мод» по имени папки.
Переименование делает его другим модом — состояние «включён» сбросится, и игрокам придётся включать его заново. Не переименовывайте после выпуска.

3. Напишите mod.json

Создайте mod.json внутри папки мода. Без этого файла игра не считает папку модом — он даже не появится в списке.

{
  "name": "My First Mod",
  "author": "Ваше имя",
  "version": "1.0",
  "description": "Проба. Добавляет абсурдно сильное зелье."
}

Все поля необязательны и имеют значения по умолчанию. Подробности в главе Поля mod.json.

4. Добавьте одну запись данных

Данные лежат в Data/<таблица>/, и один файл JSON — это одна запись. Вот предмет:

MyFirstMod/
├── mod.json
└── Data/
    └── Item/
        └── SuperPotion.json

Содержимое SuperPotion.json:

{
  "Name": "SuperPotion",
  "Name_I2": "Супер-зелье",
  "Desc": "Выпей — и станешь очень сильным",
  "Type": "Item",
  "AddHP": 999
}
Имя папки решает, какую таблицу вы правите Data/Item/ правит предметы, Data/Role/ — персонажей.
Принимаются и Item, и TheItem (игра сама подставит The).
Имя файла значения не имеет — игра читает поле Name внутри файла.

5. Включите и проверьте

  1. Вернитесь в игру: главный экран → Менеджер модов
  2. Найдите «My First Mod» и нажмите Включить
  3. Вернитесь на главный экран, затем «Новая игра» или «Загрузить игру»
  4. Зайдите в магазин — «Супер-зелье» должно быть там
Изменения применяются при входе в игру с главного экрана Данные модов объединяются в двух случаях: Новая игра и Загрузить игру. После правки файлов или переключения мода вернитесь на главный экран и войдите снова — перезапускать игру не нужно.
Уже начатая сессия не изменится: нужно вернуться на главный экран.

Получилось?

Видите новый предмет → вся цепочка работает Дальше читайте Правку данных игры, чтобы научиться менять существующее содержимое и узнать, какие поля доступны.
Не видите → переходите к решению проблем В главе Решение проблем есть таблица сообщений об ошибках и проверки по симптомам. В девяти случаях из десяти это синтаксическая ошибка JSON (пропущенная или лишняя запятая).

Как выглядит полный мод

Мод, использующий все возможности:

MyMod/
├── mod.json              удостоверение (обязательно)
├── icon.png              миниатюра в списке (необязательно)
├── Data/                 таблицы данных
│   ├── Item/
│   │   └── SuperPotion.json
│   ├── Role/
│   │   └── NewHero.json
│   └── Skill/
│       └── MegaSlash.json
├── Images/               графика
│   ├── RoleHead/
│   │   └── NewHero.png
│   └── Role/
│       └── NewHero.png
└── Music/                аудио
    ├── BGM/
    │   └── BGM_MyTheme.ogg
    └── Sfx/
        └── se_MyHit.ogg

Каждая часть разобрана в следующих главах.

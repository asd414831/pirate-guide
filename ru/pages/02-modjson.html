Поля mod.json

Удостоверение мода. Именно оно решает, что игрок увидит в списке модов.

Куда его положить

Mods/<папка вашего мода>/mod.json
Нет mod.json — нет мода Просматривая Mods/, игра считает модами только те вложенные папки, в которых есть mod.json. Без него папка полностью игнорируется — в списке она не появится, и сообщения об ошибке тоже не будет.

Полный пример

{
  "name": "Harder Pirates",
  "author": "Некий игрок",
  "version": "1.2.0",
  "description": "Враги бьют сильнее, добыча выпадает реже.\nРассчитано на новую игру+.",
  "icon": "icon.png"
}

Справочник полей

ПолеТипЕсли не указаноПримечания
nameтекстберётся имя папки Отображаемое имя в списке модов. Любой язык.
authorтекстпоказывается «Автор неизвестен» Ваше имя или ник.
versionтекстпоказывается «-» Только для отображения. Игра никогда не сравнивает версии — 1.0 и v2-beta одинаково допустимы.
descriptionтекстпусто Описание. Для переноса строки используйте \n.
iconтекстicon.png Относительный путь к миниатюре. Если файла нет, подставляется стандартное изображение.
Все поля необязательны Работает даже пустой {} — игра возьмёт имя папки. Пропуск поля никогда не ломает мод. Так задумано.

Миниатюра

По умолчанию игра ищет icon.png в папке мода. Чтобы использовать другое имя или вложенную папку:

{
  "icon": "art/my-thumbnail.png"
}

Путь считается от папки вашего мода, а не от Mods/.

Переносы строк

Строки JSON не могут содержать настоящий перенос строки — используйте \n:

{
  "description": "Первая строка\nВторая строка\n\nТретья после пустой"
}
Экранируйте обратные слэши в путях Windows \ в JSON — особый символ. Используйте прямые слэши в пути icon — art/icon.png, а не art\icon.png. Настоящий обратный слэш нужно удваивать (\\), и здесь легко ошибиться.

Что будет при ошибке в файле

Если mod.json есть, но содержит синтаксическую ошибку (пропущенная запятая, лишняя запятая, незакрытая кавычка), мод всё равно появится в списке, но будет помечен как повреждённый.

Так задумано Если бы повреждённые моды просто исчезали, игрок решил бы, что файлы лежат не там, и не смог бы это проверить. Показать мод и пометить его — значит сказать: «он на месте, но с ним что-то не так».

Частые ошибки JSON:

{
  "name": "My Mod",
  "author": "Кто-то",     <-- лишняя запятая в последнем поле
}

{
  "name": "My Mod"
  "author": "Кто-то"      <-- нет запятой между полями
}

{
  'name': 'My Mod'         <-- JSON требует двойных кавычек
}
Правка в VS Code избавляет от девяти таких ошибок из десяти Он подсвечивает синтаксические ошибки прямо при вводе. Как вариант — вставьте файл в любой онлайн-валидатор JSON.

Не переименовывайте папку

Состояние «включён» привязано к имени папки, а не к полю name Менять name в mod.json безопасно: меняется только отображаемое имя.
Менять имя папки — для игры это другой мод: состояние «включён» сбросится, и игрокам придётся включать его заново. Не переименовывайте после выпуска.

Руководство по созданию модов Pirate

Программировать не нужно. Умеете пользоваться текстовым редактором — значит, сможете делать моды.

Это руководство о создании модов для Pirate — как добавить предметы, изменить характеристики персонажей, заменить графику, подключить свою музыку. Всё делается правкой текстовых файлов. Никаких инструментов разработчика и перекомпиляции игры.

Первый мод займёт пять минут Создайте папку, напишите один mod.json, положите один файл JSON. Всё. Сразу к делу: Быстрый старт.

Что можно сделать

  • Менять значения — персонажи, враги, навыки, бафы, предметы, этапы, местность… все 13 таблиц данных игры доступны для правки
  • Добавлять новое содержимое — не только править существующее: можно добавлять совершенно новые предметы, персонажей и навыки
  • Подключать свою графику — положите PNG в Images/, и они загрузятся; добавляйте новые портреты или заменяйте игровые
  • Подключать своё аудио — OGG / MP3 / WAV в Music/, и фоновая музыка, и звуковые эффекты
  • Собирать целые бои — свои враги, их ИИ, этапы из нескольких волн, боевые фоны
  • Писать сюжетные сцены — диалоги, портреты, варианты выражений лица, вступления и финалы этапов

Что сделать нельзя

  • Удалять существующее содержимое — моды могут только менять и добавлять. Чтобы что-то спрятать, используйте UnlockCon (см. Правка данных игры)
  • Добавлять новую программную логику — C# недоступен. Но команды сценария и система постановок и так довольно гибкие
  • Пользоваться модами на мобильных — только на компьютере
